# ADR-105：受控 Skill 草稿与不可变发布登记

日期：2026-10-15。状态：登记实现的决策与边界补齐；M6 整体验收待完成。

## 背景

已有 Skill 由仓库打包并绑定 Rust 预置只读模板，AIRun 固定 id/version/digest。M6 需要在既有 Java 平台内管理配置草稿、审核和发布历史，同时保持四个启动单元、可信身份、已发布内容不可覆盖和执行器共享预算。现有登记领域、HTTP 和 V073 已提交为开发进度，本 ADR 不把文件存在视为验收。

## 决策

### 2.1 所有权与内联配置

Java `ai-control` 拥有草稿、版本、指针和命令回执；使用已有 PostgreSQL `ai_control` schema，不新增数据库、微服务、执行器或动态代码。领域类型不依赖 Spring/JDBC/HTTP。配置是内联文本、固定模板、Tool pin 子集、预算和有限案例，不提供脚本、容器、文件路径、远端下载位置或请求身份字段。详细字段、限额和当前校验局限以 [Skill 契约](../../contracts/skills.md) 为准。

### 2.2 可信范围与职责分离

当前 Principal 构造租户与主体；写操作要求 `skill.manage` 及对象授权，单 Skill 读取要求 `skill.read` 及对象授权。草稿列表要求整个租户或显式 Skill 通配范围，尚不提供窄范围过滤分页。跨租户草稿不可见。模型或配置不能增加任何 Tool、数据、动作或预算权限。

发布是审核批准行为，要求当前发布者不同于最初作者。当前实现固定最初作者而未记录所有编辑贡献者；其他有权管理者也可修改草稿，因此尚不证明完整逐修订四眼审核。公开投影不输出作者/审批主体；可信主体在私有存储列中保存。

### 2.3 内容摘要与不可变版本

`DRAFT → IN_REVIEW → PUBLISHED`；保存带 editVersion CAS，审核中显式保存撤回到草稿，已发布坐标不能再写。审核提交不执行检查，发布在事务写入前重新计算有限检查并与冻结摘要匹配。发布版本只追加，保存内容摘要与批准时间；发布指针单独保存。

内容摘要使用 `opsweave-skill-content-v1` 和有序长度前缀 UTF-8 输入，精确算法见契约。它与打包加载器摘要的输入组成不同，不承诺二者可互换。已打包三个坐标保留，不能由登记版本覆盖。

### 2.4 幂等、发布和显式回退

四种命令的 requestId 在租户内共享命名空间；原种类与内容匹配时返回原回执，异内容或异命令冲突。当前回执未绑定发起主体，重放仍要求当前权限。未知结果保留原 UUID/完整命令，用户明确重发原命令，不隐藏重试；没有独立按命令 UUID 回读端点。

发布写入不可变版本、终结草稿并移动指针；回退只移动指针，带明确理由和原回执，原版本/已有运行 pin 保持。当前回退允许任何不同的已发布目标，不强制时间或 SemVer 顺序。失败的发布不得移动指针；真实事务/并发证据需独立验证。

### 2.5 模板、工具和预算

允许 `readonly-current-incident-diagnosis-v1` 与 `readonly-incident-diagnosis-v1` 两个已有模板名称。模板 Tool 白名单、预算上限由服务端检查，不允许配置自身授予权限。知识范围固定 current，副作用固定 forbidden。当前登记没有被 Runtime 消费，因此不会改变现有执行预算、模型次数、只读工具或 AIRun 固定 pin。

### 2.6 检查不是模型评估

GET check 是无模型、无工具、无外连、无持久推进的有限检查：JSON 可解析性、本地引用、顶层 required/properties/basic type 及模板门禁。它不完整执行 JSON Schema，不验证推理质量、根因或真实模型兼容；`modelComparison=not-run` 永远明确保留。报告错误是闭合代码，不回显 prompt/客户原文。真实评估、版本比较、人工评审和提供方费用核对继续待实现/验收。

### 2.7 加载与内容安全

登记只存内联内容，不解析作者路径，不触发 Schema/URL 下载。现有协议/凭据标记筛查有限，不能当作完整路径或秘密扫描；服务器执行边界仍是权限和固定加载器。运行时接入前必须定义受信任解析、停用对新/在途运行的语义、digest 验证、模板兼容与共享预算，不能把 release pointer 当作已启用证明。

## 影响与验收边界

V073 使用现有 `skill_draft/skill_version/skill_release/skill_command`，有配套受限回退脚本；表的存在不证明已部署或真实 PG 通过。分页只提供有界续读，不是快照；完整时间/标识元组锚定续读，当前租户/Skill 中不存在的游标为 404。

本段交付闭合契约、合成样例、OpenAPI、HTTP 错误/分页/授权修正及测试入口；契约 Schema 正反例已执行不代表真实 PG 生命周期或并发已验证；PG 锁与 CAS 修正及竞态测试仍须实际运行。实际执行结果单独记录。S1 只有在幂等/CAS、范围拒绝、作者分离、不可变版本、失败不移动指针的领域/PG/HTTP 证据完整后才关闭。S2 的 Runtime pin 接线/停用/评估、S3 Builder、真实身份/模型/人工验收和生产可靠性不由本 ADR 宣告完成。
