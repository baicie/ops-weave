# ADR-075：有期限、可撤销的实体工作流后台授权

日期：2026-10-04。状态：实现受控实体后台授权；完整批次恢复、指标输出和生产运行门槛继续。

已发布版本、显式启动和采集启动是三个操作。原本地实体任务使用固定开发身份轮询，不能把该身份用于已认证用户的后台处理。本次在现有Java平台中增加可信授权适配器，沿用四启动单元、已有PostgreSQL任务JSON和纯Java执行计划，没有新执行服务、数据库或动态代码。

OIDC请求必须先经现有BFF认证、Origin和CSRF检查。操作员另以私有本机文件显式允许至多20个外部subject申请后台授权；默认路径为空，后台入口关闭。文件只包含schemaVersion与subjects，不授予权限，不接受请求提交或浏览器修改。每次申请从当前可信身份映射构造授权，固定原issuer、subject和完整映射摘要；租户、所有者、权限及对象范围始终由可信边界构造。

任务保存授权UUID、身份映射引用、签发/截止时间和批次预算，不保存登录Cookie、Bearer、IdP令牌、刷新令牌或序列化Principal。授权最长15分钟、最多20批，截止不晚于原BFF身份截止；无自动续期。此授权在签发后独立于浏览器登录：关闭页面或注销不自动撤销已签发授权。用户显式停止、操作员移除后台许可、映射删除/禁用/版本或范围变化、配置损坏、到期与额度耗尽都会停止后续处理。产品界面必须提前说明该生命周期，并显示期限与额度。

执行器在选取批次前、验证输出前、每条写入前和提交游标前重新解析当前私有政策及身份映射，核对租户/所有者/工作流和来源范围。配置缺失或无法读取不得缓存旧权限或回退开发身份。开发轮询跳过委托任务，委托轮询跳过开发任务。相同运行模式下可重建授权适配器，并凭原持久引用与当前政策在原期限内继续；重建不扩大期限或额度。

任务和停止沿用租户存储事务及generation门禁；共享并发上限2，每批最多5条、每用户最多20任务/200执行回执。失败写入保留已确认实体ID，但不推进原完成时间/批次ID游标。任务变为FAILED，无隐藏重试；到期、撤权与额度耗尽有稳定原因码。时间倒退、未来完成时间或非递增批次不能扩大访问窗口或推进游标。

公开任务仅增加authorization摘要五字段，执行回执只增加authorizationId。私有持久格式有独立Schema，公开API剥离issuer、externalSubject和grantDigest；客户端不能提交authority、tenant或权限。旧任务/回执JSON仍可读取，但不同授权模式不互相执行。

恢复发现只遍历当前私有政策所允许的身份；内存最多保存40组租户/所有者路由元数据，不缓存权限。运行中被移除的当前进程路由保留到任务失败为止。若身份和许可同时删除且随后重启，旧任务无法由当前政策发现，因而不会执行，但需要后续管理性对账消除持久RUNNING状态。本方案没有全局扫描权限，也不声称实现HA租约、跨进程fencing或生产OIDC部署。

当前运行来源仍是原未配置版本的ZABBIX_HOST实体批次；固定接入配置来源、标准指标时序输出及日志写入均未开放。第114节已补充启动/停止的独立幂等受理回执，见[ADR-076](076-idempotent-workflow-control.md)。显式重新启动仍从新起点处理，失败批次的完整恢复和未知业务写入结果确认继续。不能据此宣布S5完成。
