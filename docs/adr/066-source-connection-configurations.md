# ADR-066 · 实例完整连接配置与固定读取

状态：已实现本地平台配置/检查切片；完整工作流发布绑定仍待实现。

既有创建回执与摘要历史无法表达实例具体使用哪个登记地址和秘密版本。继续由单一env配置推断会在轮换、多个实例或修改过程中失去版本依据。

在现有Java集成模块增加SourceConnectionConfiguration和SourceConnectionService。公共请求仅选择已登记地址pin与固定秘密版本pin；部署目录决定出口，凭据服务决定解密，可信身份决定对象范围。完整非秘密快照与通用历史在同一PG事务只追加；创建/更新及原回执同时提交。使用instance UUID和配置版本读取，不能仅按共享物理来源ID覆盖旧实例连接。

新实例使用独立物理ID；旧Host显式绑定保留物理ID及所有创建/发布记录。名称/说明与连接语义分开版本化；错误pin、撤销、CAS冲突、档案损坏和容量上限明确失败。配置服务与检查服务复用同一WorkflowStore.Session验证秘密元数据，避免在持有PG事务锁时开启第二个凭据事务。IO仅在PENDING认领后、事务外执行，始终读取原快照并在结束前检查当前配置；结果未知不隐式重试。

Web请求容器持有可信会话、关闭保护、非秘密原命令及取消；SourceConnectionDrawer只展示字段和事件。地址、凭据、具体秘密版本分别明确选择，轮换不自动换pin；403/身份变化清空包括隐藏目标在内的缓存。历史首次可见读取一次、失败手工刷新，普通关闭保留草稿并提供继续/放弃入口，未知结果仅查询原回执。已有维护抽屉与创建记录列表把新连接导向实例配置。

代价与后续：部署地址目录目前仍启动固定，数字IP及现有JSON-RPC适配器边界不扩展；密钥环没有获得生产KMS或备份恢复证明。首分页发现不是完整模型/指标发现。工作流发布尚未携带新配置完整pin，新连接不自动创建流程、发布或启动任务；下一阶段必须先提供可审查的来源绑定与版本差异，再完成可信后台执行。保持四个启动单元、单PG和跨语言契约唯一源。
