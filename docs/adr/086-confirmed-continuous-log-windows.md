# ADR-086：确认后推进的持续日志窗口

状态：已实现本机受限执行；生产退出条件仍待验收。

在 [ADR-085](085-bounded-complete-log-window-ports.md) 完整窗口端口上增加持续任务，复用平台进程、可信会话、来源注册、固定算子、共享并发和现有日志库，不新增数据库或启动单元。窗口级 PostgreSQL 证明只存不可变位置、摘要和计数，避免逐日志正文进入业务库。

控制命令以原 UUID、操作和代数绑定不可变快照。批次提交 IN_FLIGHT 证明后才发一次日志写入，独立完整回读确认后推进时间。停止与本机输出在 tenant 事务锁内串行化；来源读取位于事务外，输出前再次检查任务代数、身份、授权与固定版本。请求或写入结果未知时只核验原批次，不能凭客户端重试推断未写入。

迟到补采以纳秒采集位置识别，而非正文或 provider eventId。回看上一分钟时核对原全输入位置及摘要，保留被过滤的旧记录。新批次仅包含新增接受位置，旧接受记录计入去重，新增过滤记录也更新证明；窗口与 checkpoint 不动。补采消耗批次额度，元数据漂移、来源历史变化或超限均暂停。

页面请求容器与任务展示、日志分页展示分离。展开后读取状态，运行时有限轮询；失败后显式刷新。每页 50 条，服务器每次按完整证明校验原批次，保留全站 HTTP 2 MiB 限制。正文纯文本、清理身份/隐藏页正文缓存，原控制待确认仍保留关闭门禁。

范围不含更早迟到数据、历史修订覆盖、UNKNOWN 放弃、分布式租约/fencing、生产容量/保留期或新生产认证。输出确认是本次完整回读证明，不能推断复制耐久性。见[契约](../../contracts/workflow-log-streams.md)和[操作说明](../runbooks/workflow-log-streams.md)。
