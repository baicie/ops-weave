# ADR-063：固定配置的显式检查与字段发现

日期：2026-10-03。状态：采用。完整连接及凭据配置后续实施，生产运行退出门槛保持。

接入实例维护需要明确区分保存、测试、发现与运行。增加显式v2命令，每条记录固定实例配置版本、摘要、开始时间和请求键；可信身份与来源授权在服务端执行，浏览器不能提供网络地址或身份。既有部署登记连接复用原连接器，Java领域/应用层只依赖Reader业务接口，不依赖HTTP、Spring或厂商DTO。

请求先事务持久化PENDING，来源IO在事务外，最后重新核对固定配置并保存终态。相同请求仅回读元数据，避免客户端超时后重复探测。沿用PG租户事务和条件更新来保证原请求只认领一次；进程并发为2，不以此宣称全局分布式预算或运行租约。结果接受期限65秒，完成后有效15分钟；超期或配置变化不能生成可信完成结果，丢失回执可只读查询。没有自动轮询、自动补页、重试或接管。

连接测试必须包含授权主机读取，匿名版本响应不足以证明连通权限。字段发现只读首个主机分页（最多5条），保存固定5个原始字段的观察类型/缺失和指纹，不保存来源值。完整清单、部分分页、未验证方法、不可达和UNKNOWN分别保留；发现不修改字段映射或资产，也不启动采集。

已有env凭据引用不是固定密钥版本，真实来源检查一律不能作为可复用凭据pin。本次授权读取的READ_VERIFIED与总体有效性UNVERIFIED可以同时存在。完整凭据管理、受控多连接配置、发布pin和后台委托需继续实施，不因新增检查记录而视为完成。详情见[契约](../../contracts/source-inspections.md)。

前端请求与待确认状态在SourceInstancePanel，SourceInspectionResults仅渲染结果。首次打开连接页签只读取历史一次；探测/发现均需按钮触发。结果未知锁定修改，使用原请求查询。403清空会话下缓存并关闭抽屉，迟到响应不得恢复；普通读取失败保留错误，显式刷新。页面到期更新标签不发网络请求。原创建快照和已发布流程保持不变。
