# ADR-093：单次样本未知输出的明确终止确认

状态：已接受。日期：2026-10-05。

单次指标和日志输出可能已写入但无法确认。原 UNKNOWN 证明阻止发起下一次样本请求，需要一个保留不确定性的明确出口。将它改成失败或成功会丢失事实，重新写入原请求也不能证明没有重复。

采用独立、不可变的样本终止事件。原证明继续 UNKNOWN，原输出、计数、发布时间和游标保持。终止不执行来源读取、求值、输出读取或写入，只在已有 PG 元数据事务中记录决策；纯 Java 服务仅依赖 WorkflowStore 和 Clock。既有四启动单元及数据库保持。

命令绑定原 batch UUID、发布 ref、batchDigest 和精确 updatedAt，并要求 acknowledgeUncertainOutput=true。可信身份须拥有本人证明、工作流与固定来源 SOURCE_SYNC，以及精确目标指标 METRIC_READ，或目标日志 LOG_READ/LOG_WRITE。原 UNKNOWN 之外的状态拒绝。每个 owner 跨两种样本最多200事件；同命令 UUID 同内容幂等，一个原批次只接受一个事件。

V053 的类型化外键连接原指标或日志证明，唯一键阻止重复终止。读取校验数据库索引列、闭合 JSON、摘要和原父证明。终止成功后原验证入口在输出读取前拒绝，存储 refinement 再次检查，阻止核验读取期间发生的终止被覆盖。核验先确认则终止 CAS 失败。原请求重放仍返回原 UNKNOWN，不发起写入。

Web 使用共享请求容器和纯展示组件。选中 UNKNOWN 时首次读取一次终止元数据；这是状态查询，不是输出核验。用户勾选后提交一次，丢失回执保留原 UUID，原查询404后才能原内容重发或明确放弃本地确认。未确认命令阻止折叠、版本切换和关闭。会话变化清私有状态，隐藏取消读取，迟到响应隔离，无自动重发。

终止只关闭原批次的确认流程。新 UUID 样本仍需明确操作和当前权限；不能据此声称时间范围去重、历史补偿或质量成功。历史质量保持未知。生产租约/fencing、保留、跨版本重放和生产身份是后续独立工作。
