# ADR-098 · 固定历史指标窗重建

状态：实现；实际检查见[验证报告](../VALIDATION-REPORT.md)第136节。

检查历史不提供重新执行。固定发布版本增加独立历史选择和指标投影重建，沿用Java平台、受控来源、编译计划、共享有界IO预算及既有PG/VictoriaMetrics。没有新增启动单元、数据库、调度线程、动态执行器、通知或动作端口。

重放需要当前可信`workflow.replay`权限与workflow对象范围，同时保留原`source.sync`、指标、实体、来源、连接和固定映射门禁。默认身份权限不扩大。浏览器只提交固定版本、60秒范围及原UUID；tenant、subject、权限、原始点值、来源地址和输出标签均不接受请求提供。

第一步在IO前持久PREPARING，读取过去24小时内已结束至少10秒的60秒窗，最多60条，运行原固定转换并封存输入摘要、输出摘要、计数、时间戳和系列标签。原始值只在内存与时序引擎。READY选择有效10分钟；重复请求返回原记录，不重新读取。PREPARING中断保留待确认，不能从进程退出推断来源为空或自动继续。

第二步显式确认绑定原选择和两个摘要。每个选择只能有一个执行UUID；先持久PENDING，再重新读取同一历史窗，严格匹配完整输入和输出证明，并在输出前复核当前门禁与有效期。来源新增、缺失、值变化或顺序变化都拒绝输出，不能偷偷以新输入替代。历史选择是当时重新读取的来源数据，不承诺曾经未保存的原始快照。

结果写入带`collection_mode=REPLAY_60S`和`replay_id`的独立指标系列，保留固定工作流、配置、映射、指标和维度。持续采集系列、任务状态、授权和checkpoint不改；此用途明确为重建独立投影，不提供覆盖原采集值、日志补写、资产修复或批量回填。时序库不增加新的业务事件或通知消费。

输出端原有精确回读契约保持。写后未确认保留UNKNOWN，明确拒绝才FAILED；原请求重放只回读，不重读来源或重写。显式核验只查询原系列/时间戳并比较摘要，完整匹配后才CONFIRMED。仍在PENDING且受理不足180秒时核验保留原状态，避免对尚在执行的请求过早空读；超过此时间也不能推断未写入。此保护不是分布式租约或fencing。

已有PG保存选择与执行证明；租户事务锁、类型化父版本外键、唯一选择执行键与纯领域refinement防止并发双受理、更换原证明或UNKNOWN降为拒绝。本人最多200个选择；最近20列表是有界查询，不是生产留存策略。回退在存在任何选择/执行记录时拒绝，不能丢弃待确认或已确认历史。

Web使用请求容器和纯展示Panel。默认折叠且不调用来源/输出，展开仅读取元数据一次。先检查范围/数量/完整指标键，再明确确认；非法或丢失回执保留原UUID，只有原回查404才允许原样重发。忙碌/本地待确认阻止折叠、版本切换及页签关闭；身份变化取消请求并清除私有状态。服务端UNKNOWN可通过显式核验读取，不能画成失败或自动重放。

本节是有界指标重建闭环。日志/资产重放、覆盖修复、关闭未确认重放、生产留存/容量、公平调度、租约/fencing/HA与生产身份持续链仍需独立实现和验收；不把前台幂等或回读称为跨存储exactly-once。
