# ADR-071：来源指标清单的受控分页

日期：2026-10-03。状态：已实现并完成本机验证；不是生产准入结论。

首分页发现最多展示20项，超过20项只能说明发现不完整。接入维护需要逐页核对完整来源键、单位、类型及标准映射，不能让客户端携带任意游标、来源URL或指标ID扩大读取范围。

继续使用平台Java模块、可信Principal、固定连接配置、已有检查回执表及四个启动单元。新增DISCOVER_METRIC_PAGE命令，只接受requestId、configurationRevision、connectionDigest、previousRequestId。首次previousRequestId为null；后续只能引用同一身份、租户、实例和配置下已确认且有效的上一页。服务器从上一页推导位置，完整有序ID清单保存在私有回执中，公开接口只返回清单id、时间、数量和指纹。

每次最多五个固定item.get请求：读取排除模板的数量和最多1001个ID、精确读取所选最多20项元数据，再核对数量及完整ID清单。可接受的清单容量为1000项，最多50页。超容量、清单变化和读取失败保留为显式状态；不返回伪造的空完整结果，不读指标值或history，不自动启用绑定、采集或输出。成功的空清单与失败不同。

首次请求时间固定清单的15分钟有效期，后续分页不延长它。每个请求沿用65秒期限、请求前持久PENDING、同键同命令只查询原回执的规则。不同上一页或配置使用同键返回冲突。来源配置、归档、地址或凭据可用性在网络前后核对；不成立或执行失联保留UNKNOWN，无隐藏重试或Fixture回退。源与检查读取沿用有界并发，数据库事务不跨网络等待。已有每身份200份回执限制继续生效。

公开wire与私有storage编码分开。SourceMetricPage领域构造器核对有序清单、精确页ID、指纹和时间谱系；读取持久回执时核对根回执、直接父回执、固定配置和来源授权。旧Host及首分页指标回执、摘要和接口保持可读。使用已经迁移的256KiB回执预算，不添加数据库、表或启动单元。

Web请求容器持有原命令和最多200份当前实例回执缓存；SourceMetricTable与SourceMetricPageResults仅负责展示。上一页查询原回执；缓存中的下一页直接展示，尚未读取的下一页才显式发起新命令。网络响应尚未确认时保留原命令并锁定新操作；身份变化清空缓存。当前配置与完整覆盖分别展示，清单变化需重新发现，根有效期到期立即禁用继续读取。完整标准指标键链接到对应定义。

ITEMID_WATERMARK只保证已观察到的清单成员及连续分页范围，不是来源所有可变元数据在同一时刻的原子快照。各页字段是当次观察值；两次读取之间发生再恢复的变更无法凭此证明。它不能充当采集checkpoint、删除资产依据或工作流独立映射执行pin。完整模型字段、映射执行版本、可信后台委托、持久批次与真实输出仍继续实施。验证证据与未运行范围见验证报告§109。
