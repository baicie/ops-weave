# ADR-073：工作流标准指标输出与固定映射

第112节后续实现：[ADR-074](074-fixed-metric-workflow-sources.md)补齐固定真实指标来源、原始值读取和系列出处。下文保留第111节当时的手工样本范围；持久输出及后台执行仍未由此完成。

状态：已实现样本预览与版本管理；真实指标来源、写入及持续任务另行推进。日期：2026-10-04。

现有通用METRIC格式由输入提供指标标识、类型与单位，无法证明应用了目录中的数值转换、范围和维度。新增METRIC目标格式1.1，明确固定完整指标标识和映射id/revision/digest；旧实体、日志和METRIC 1.0目标保持原格式与语义摘要。新目标版本、完整标识和pin参与工作流摘要及版本差异。

可信身份先通过source.sync和目标metric.read对象范围，执行计划再解析登记的完整映射。规则不从浏览器传入，不自动采用最新版本。新草稿保存、新预览和新发布要求相同定义仍可执行；预览保存回执前再次核对定义。目录失配返回MAPPING_CHANGED，不保存部分成功回执。历史定义和元数据回执使用存储中的完整指标标识授权，保留原pin；已确认发布的原样重试不依赖当前目录重新编译，也不解除当前身份检查。

1.1当前支持数值GAUGE、DOUBLE/INTEGER且维度全部固定的登记规则。MAP仅映射timestamp、sourceKey和value；VALIDATE检查精确来源键、时间和原始数值类型，执行登记的identity/multiply转换及归一化范围。单位、指标类型、完整标识、固定维度和pin由执行计划产生，客户端不能覆盖。OUTPUT只接受该计划校验后的封闭结果。未知转换、非数值类型、非GAUGE、动态维度或超出记录预算的定义在编译阶段拒绝。

标准结果保留精确十进制字符串，最多64字符；结果仅允许七个字段和4096字节。嵌套维度与pin只允许出现在成功的VALIDATE/OUTPUT结果中，输入及其他步骤继续限32个标量字段。前端使用完整定义摘要和精确十进制范围比较核对结果，不能用浮点四舍五入放过越界值。领域层保持纯Java，框架及HTTP只在平台适配层。

工作区同次授权读取提供映射定义；纯WorkflowMetricMappingConfig展示与选择，页面持有目录、Definition/Layout、撤销及请求。选择改变目标、MAP和连线并使旧预览失效；完整键跳转指标定义，摘要按需展开。缺失或不兼容的固定版本保持可读，不自动替换、不允许预览。示例只经明确按钮填入，标记Fixture，不随草稿保存。

本阶段仅使用MANUAL_SAMPLE进行只读预览和不可变发布，ZABBIX_HOST仍只提供实体元数据。标准结果不是已持久化的指标点；没有新增来源采集、工作单元、数据库或任务权限。运行历史继续只保存节点状态、原因及目标元数据，不保存输入和输出正文。受控指标来源、系列身份、持续写入和可撤销后台授权仍是后续验收范围。
