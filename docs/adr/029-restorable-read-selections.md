# ADR-029：URL 恢复资产、Incident 与指标只读选择

状态：采纳。日期：2026-09-25。

## 背景

M1 要求资源筛选和时间范围可还原。现有页面刷新后丢失筛选，指标也重新按当前时间取窗口，导致复制链接、返回列表或刷新后的结果难以对照。开发凭据只在内存这一边界必须继续保留。

## 决策

1. 延用 hash 路由，定义三个 canonical selection Schema 和 URL 编码规则，见 [契约](../../contracts/view-selection.md)。资产保存已应用的名称/IP、类型、生命周期、UUID 游标和选中 ID；Incident 保存状态、游标和 ID；指标保存 Host 筛选/游标、Entity、metricKey、range，以及实际查询的 from/till。
2. URL 只描述读取选择。禁止身份、凭据、缓存结果、操作名称、导入正文、状态变更正文和幂等键。恢复地址不自动联网；服务端继续逐次授权，固定资源链接也必须重新读取详情/指标目录。目录已无该指标时失败，不静默选第一项。
3. `useViewLocation` 在当前页处理 popstate/hashchange，去重同一地址的事件；本页更新用 pushState(null)，不触发自身恢复清空结果。回退/前进、切换 hash 和刷新恢复表单，取消旧请求并清除数据。URL 不恢复 React/Zeus 状态或任意可执行对象。
4. 输入框草稿与已应用选择分开：读取时保存筛选，翻页和选中资源时更新地址。指标点击查询后固定实际秒级窗口；点击 Last 范围后下一次查询取最近窗口。固定窗口破损不得 fallback 最近值。
5. 初次输入开发 Token 到首次读取前保留链接选择，包含逐字输入而非只支持粘贴。对已发出读取或进入页面时已有凭据的会话，更换凭据清除当前选择；401/403、注销或到期也清除选择。所有凭据变化始终取消请求并丢弃结果。pagehide 只保留 URL 的读取选择，凭据和结果仍清除。浏览器此前的历史不能被应用删除，访问旧历史仍是未受信输入；不能当作权限或结果缓存。
6. 无效链接展示明确错误并阻止读取，显式“重置筛选”解除；不自动修改无效 URL。实时 UUID 游标不保证跨页一致快照，不根据恢复游标虚构页码或总量。

## 影响和限制

不新增数据库、服务、后端 API、模型 Tool、认证或自动操作。查询词与资源 ID 出现在本地浏览器历史，可复制分享；不能在搜索词放秘密。诊断执行输入、关联调整/流水线操作和历史子面板筛选不纳入此版恢复协议。已有专门只读结果链接保持原行为。

Zeus 原生 select 的初次 value 写入可能早于动态 option 挂载；对 Incident 状态和指标/Host option 显式绑定 selected，避免内部值与显示值不一致。浏览器测试必须检查第二个指标和非默认状态的实际显示，再检查发出的 API 参数。

## 验证与回退

执行记录见 [验证报告第 35 节](../VALIDATION-REPORT.md)，复现见 [runbook](../runbooks/view-selection.md)。URL 负例、恢复后的显式读取、旧响应、凭据替换和下拉框一致性纳入 Web 回归；本机 Java/PG/VM 链路核对刷新前后的资源与同一实际时间窗口。回退仅涉及 Web；老版本只能识别原来的固定指标三参数链接，不承诺接受新增筛选参数。没有存储迁移。
