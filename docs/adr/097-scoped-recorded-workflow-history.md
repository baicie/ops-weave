# ADR-097 · 固定版本检查历史与稳定翻页

状态：实现；实际验收见[验证报告](../VALIDATION-REPORT.md)第135节。

最近20条诊断无法定位更早的记录。运行记录页增加本人、tenant及固定发布版本的来源与转换检查历史；原预览/版本测试单独展示，原诊断与输出协议保持。`RECORDED_CHECKS`仅覆盖已保存的检查，不能代表所有历史执行、输出确认或生产留存承诺。

Java应用服务经当前可信身份重新检查来源、目标、版本和逐实体范围，包括前页锚点及下一页检测记录。沿用已有事务与PG，查询不调用来源、输出、通知、动作或授权签发端口。第一页固定服务器时间、插入序号水位和数量；后续按完成时间降序、UUID升序，以锚点取20条并检测下一条。新记录即使回填较早时间也不进入旧快照。删除、数量变化或到期返回409，损坏返回503，不能当空成功。

V055在既有诊断表添加服务器生成的identity序号及唯一约束，不改观察正文/时间。序号仅内部使用；AES-256-GCM游标绑定可信tenant、本人、工作流ID、revision和digest，隐藏全局序号及私有选择元数据。随机nonce，10分钟有效期，每页最多20条、本人原200条容量保持。客户端验证固定快照、数量、连续offset、排序、唯一UUID和父版本，不合并失配页。

密钥经部署控制的`OPSWEAVE_HISTORY_CURSOR_KEY_REF=env:NAME`解析，值为规范Base64的32字节材料。生产缺少或显式无效配置时此读接口503，不回退开发密钥。仅开发模式且未配置引用时生成进程随机密钥；重启使旧游标失效，用户需刷新。设置相同密钥可跨适配器重开读取，不等于已完成多副本租约、fencing或HA验收。密钥不来自请求、日志或契约正文。

Web请求容器拥有会话、固定选择、取消及忙碌关闭门禁，纯展示组件与原诊断复用节点详情。活动页会话就绪后目录和默认版本各读一次；更多页及刷新显式触发，失效保留已显示的只读快照和错误。403全局清理，迟到响应不能恢复私有状态。主题/尺寸或已加载视图切换不重复读取。

不新增启动单元、数据库、线程、依赖或隐藏执行器。本节没有执行重放、通知或自动保留；后续重放仍需固定输入/输出绑定、独立范围/预算和原UUID不确定性边界。多副本及生产身份仍需独立设计与实际验收。
