# ADR-089：主机分页检查统计与实体范围见证

状态：已接受，当前有界单执行器阶段。

固定接入的主机分页已有原批次和确认后检查点，但准入前拒绝没有节点统计。沿用现有 Java 执行器、一次转换评估和 V049 元数据表，在新分页首次读取及校验时记录处置。每页最多 5 条；主机的 from/till、单位异常、采样率和排队时间均为 null，分页完整不能代表整个来源清单完整。

来源返回的每个规范实体 UUID，包括随后被过滤或拒绝的记录，进入私有范围见证。公开投影没有实体清单或输入正文。已知 received 必须等于见证数量；读取时逐实体验证当前 ENTITY_READ。来源种类必须与固定发布版本相符；正常检查关联已提交的原批次，查询重新核对版本、记录数量和实体集合，损坏或失配失败，不返回空成功。

检查容量在来源 IO 前验证，追加前重新检查可信身份、固定版本、任务代数及原扫描/分页状态。停止竞态不留下过时代数的统计或输出。200 条本人容量耗尽暂停任务，不隐藏重试或删除证据。来源返回前、权限或准入失败没有完成处置时保留不可用；不从错误码推算分母。

节点校验拒绝保留一次实际统计，并回滚分页批次准入：不输出，不推进检查点。正常检查关联已提交的 READY 批次；元数据追加失败保留原待处理分页并暂停，不能虚构成功。输出状态仍由原批次负责。UNKNOWN 显式恢复继续原私有分页，原检查不可变，不再次读取来源或重复追加统计。

增加私有 `workflow-diagnostic-stored` Schema，公开四份检查协议及原控制、输出和质量协议不变。没有迁移、新增数据库、执行框架或启动单元。旧的未固定连接主机任务仍沿用原路径，不宣称有新增统计。保留策略需协调原批次和关联统计；生产保留、容量治理、排队统计、告警、历史修订和分布式租约/fencing 仍待实现。
