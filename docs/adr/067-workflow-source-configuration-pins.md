# ADR-067：工作流固定来源配置

状态：已接受；固定版本与只读预览/发布已实现，实际检查见验证报告第104节。持续运行边界保持待实现。

维护实例已有不可变的地址、凭据版本和连接器快照，工作流仍只引用旧物理来源和采集批次。把新实例直接映射到全局连接会丢失版本语义，轮换后不能证明实际使用的地址和秘密版本。

工作流来源增加可选的`configuration`，只包含`sourceId/revision/digest`。服务器在同一租户事务中查找私有实例的完整不可变配置历史，核对物理来源、版本和摘要。完整快照的摘要已经覆盖连接器版本、登记地址pin及秘密版本pin，因此无需在每个流程中复制地址或秘密元数据。新pin参与流程语义摘要；不含pin的旧定义保持原序列和摘要。请求不能提交tenant、权限、任意地址、秘密或latest别名。

保存、预览前后与发布都复核固定配置和当前可用性。连接轮换不更新流程pin；旧秘密版本未撤销、地址登记摘要未改变且实例未归档时可继续显式使用旧版本。历史草稿、版本与运行元数据读取校验对象范围和配置历史，不要求秘密当前可执行；撤销不删除审计记录。当前实例仍按创建者隔离，读取其他创建者的来源不会提升权限；跨创建者共享来源需独立设计。

固定来源预览显式读取最多5条Host记录，不接收手工样本或旧syncRunId。复用数字地址出口策略、固定秘密读取及前后撤销检查、有界manifest和既有Host映射，逐实体检查ENTITY_READ。外部IO在工作流存储事务之外，返回后再次核对当前草稿CAS和固定依赖；未通过复核不保存成功回执。仅保存数据摘要和运行元数据，不保存输入/输出正文。trace同步批次ID为null，说明这是有界即时读取；retainedCount在该路径表示实际读入样本数，不表示已经持久化原始批次。截断和失败不假装成完整采集。

当前旧运行器只消费既有保留批次；遇到固定来源主动返回SOURCE_UNAVAILABLE，不将即时预览当成已采集可写批次。持续运行仍需固定配置的持久采集谱系、可信可撤销后台委托和幂等输出，不能缓存浏览器Token或在持有PG事务时执行网络读取。保持四个启动单元及已有数据库，不引入新编排框架或动态代码。

页面由WorkflowSourcePanel管理身份、读取、取消、失败和选择缓存，WorkflowSourceConfig只展示字段及事件。打开选择器才读实例列表，版本明确选择并通过“使用此版本”应用；失败只显式重试，旧流程不自动迁移。完整pin可换行，发布来源只读。
