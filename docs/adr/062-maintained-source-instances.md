# ADR-062：接入实例元数据、配置版本与原始回执

日期：2026-10-03。状态：按已授权的后续实施采用；运行与生产退出项单独验收。

来源创建回执是不可变的确认结果，不足以承担日常维护。增加独立SourceInstance聚合，复用原创建ID与四启动单元中的integration事务，不覆盖SourceSetup或已发布工作流。旧记录读取时投影为实例初版，读取不执行迁移或写入；首次编辑原子保存初始配置、实例变更及命令回执。

实例编辑使用expectedEditVersion；名称/说明修改只增加editVersion，显式选用新的服务端连接摘要才增加configurationRevision。配置版本与命令回执只追加，已发布工作流/任务不隐式改版。来源种类与物理来源ID在创建后固定。归档保留全部历史，当前主体的RUNNING任务存在时拒绝归档；归档不是停止其他主体任务、撤销来源授权或删除已发布工作流。恢复归档也是显式CAS命令。

v2 API与原v1回执并存。命令requestId在租户/主体范围内唯一，相同命令返回原实例回执，内容变化409；失败或客户端中断不换键自动重试。接入记录每主体200份，返回最近20份并标记截断，配置版本最多100，实例editVersion最多1000，维护命令最多200；容量满时拒绝，不自动删除旧证据。

连接引用只来自可信部署配置。首个连接器沿用已登记Zabbix Host与手工样本；浏览器不提交URL、secretRef或明文秘密，不扩大网络出口。新增服务器地址/密钥配置仍由部署边界管理；UI实例新增不等同新增任意远端连接或密钥存储能力。测试和字段发现须独立显式操作，结果绑定配置版本/摘要，失败与不完整数据保留。本ADR不新增数据库、服务、任意HTTP/脚本或生产后台身份。

接入实例维护在数据源中心独立展示，原创建记录与版本导航保持兼容；维护抽屉保留CAS冲突、请求待确认与身份取消。实施状态与真实检查以验证报告为准。
