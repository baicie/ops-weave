# ADR-065：新增来源使用部署登记地址与固定凭据版本

- 状态：接受，§102完成目录与内部读取边界；实例绑定继续实施
- 背景：§101已有独立凭据版本，而旧连接仍只读取一个部署env配置。若直接把地址输入框连到HTTP客户端，来源配置可能成为任意代理，地址变化和秘密轮换也会改变原检查语义。

在四启动单元内增加纯领域地址pin、目录端口与授权服务；platform-api加载仓库外本机部署文件，不新增服务或数据库。登记包含明确租户列表和闭集连接器类型，响应按可信主体范围过滤。新增目录默认空，不自动迁移旧连接，不自动授予权限。读取元数据允许source.sync或source.configure；实际IO要求source.sync及source、source-endpoint、credential对象范围全部允许。

可信操作员文件的scope枚举同步加入source-endpoint和credential，避免只有tenantWide才能使用新增读取。文件适配器和身份契约同时修改，名称不是客户端授予的权限；每次会话重读与授权撤销规则保持原有边界。

首个新增连接仅接受数字IP，HTTPS与标准根路径为默认；回环HTTP和回环HTTPS仅显式本机dev模式允许。拒绝地址中的凭据、查询片段、编码、区号、重定向、代理和危险地址范围。数值地址消除这一实现中的DNS重绑定窗口；不把预先DNS查询当成HttpClient实际连接目的地的证明。域名、HTTPS以域名认证、反向代理路径和其他连接器需明确设计出口约束后增加，不能先放开通用URL输入。HTTPS的证书校验保持JDK默认；以IP连接要求有效证书覆盖该IP，不禁用校验或自动改用HTTP。

地址摘要绑定登记ID、连接器类型、规范地址；凭据固定完整credentialId/revision/versionId。名称修改不影响语义pin。可信内部读服务在打开秘密后、IO前后核对地址，在IO前后核对凭据版本/撤销状态，最后清空临时字符数组。现有连接器使用短暂String参数的擦除限制保留在文档，不声称内存已彻底擦除。返回检查/发现仅含有界元数据与缺失状态，不返回样本值。

目录在服务启动时固定加载，变更必须明确重启；失效或非法配置拒绝启动，不静默回退到环境地址。单机2并发与每请求/清单/字节预算限制当前适配器；不构成生产多副本预算、分布式租约或防火墙能力。正式出口策略、密钥系统/生命周期、可信后台委托、固定配置/工作流/模型依赖和生产容量继续按原路线验收。

当前新增GET目录及内部受控读适配器，没有公开探测/写地址接口。实例创建更新、配置快照与原请求回执将在该边界上实现；旧部署env来源继续原接口和明确的UNVERIFIED凭据语义。不会仅修改来源ID白名单就让不支持的新实例进入发布或执行。
