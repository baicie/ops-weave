# ADR-058：AntV 画布适配与按任务导航

日期：2026-09-28。状态：已实现，验证记录见 VALIDATION-REPORT §74。

用户要求工作流使用 X6、资产关系使用 G6，并改善页面排版与难以理解的菜单。保留 Zeus、Java 平台、Rust Runtime 与四个启动单元。前端固定 @antv/x6 3.1.8、@antv/g6 5.1.1，由 pnpm 生成真实锁文件；按需动态加载，不加载远程脚本或 React/Vue 包装。

## 图编辑和展示

X6 适配层接管节点渲染、拖动、平移、缩放、对齐线和适应画布。领域定义与布局仍采用 contracts v2；禁止把 X6 cells/内部 JSON 作为持久协议。节点参数由既有配置面板编辑，布局变化保留语义摘要；撤销、保存、预览、发布和运行记录沿用原行为。图中端点不可自由连线，执行仍是受控单链，未实现分支/并行/循环。发布版本可选择节点和缩放但不能改布局。

G6 用于两个明确区分的视图：模型中心的关系类型示意，及平台资产的已保存一跳关系。类型图来自已授权模型目录，不表示实例已存在。资产图只读取新 GET /api/v1/entities/{id}/topology，不按名字、IP 或模型类型推断连线。空关系、unknown 来源、fixture 和截断均明确展示。图节点文本按文本处理，不注入来源 HTML；无图片URL或自动外连。会话切换/离开页面销毁实例、监听器并清理私有图数据。

## 平台边界

旧 V001 关系表只在未应用的原型 SQL 中；V031 正式创建 inventory.entity_relation（兼容已存在的原型表并补 data_mode）。本次只开放查询，未提供关系采集器、实体关系创建/编辑接口。真实关系录入/转换输出仍需后续单独实现，不能宣称关系实例管理闭环完成。迁移不插入示例或推断关系。

Java 领域 ReadEntityTopology 由可信 Principal 构造 EntityVisibility，校验 entity.read 和中心/邻居权限；PostgreSQL 在 tenant 和双端点范围过滤后 LIMIT 51，单个只读 REPEATABLE READ 快照查询中心和关系。最多50条关系/51个节点，时间使用服务器当前 asOf，只返回有效区间覆盖该时点的关系。第51条只决定截断，不暴露隐藏关系计数。源引用和原始 attributes 不返回。无权限中心与不存在中心均404，无entity.read为403；未知参数拒绝，存储异常503，不返回伪空图。Memory 模式明确不支持实际关系查询。

受限平台运行角色仅增加新表 SELECT；没有关系写权限。source_ref 仍为存储字段，不送浏览器；data_mode 默认 unknown，不能据此称真实来源。Fixture不升级为真实。

## 页面与菜单

默认入口变为开始使用，提供接入→编排→运行结果路径，区分模型、实例、采集与转换。主菜单保留业务入口，旧Host流水线/CMDB导入/绑定纠错单独放接入维护；原路径兼容。Incident、Skill、Agent用中文任务名称。所有业务页面有可展开的用途、步骤和下一入口说明，页面搜索保留路径和业务关键词。桌面、窄屏、明暗主题共用排版基础。只保存主题偏好，不持久保存Token或业务图数据。
