# ADR-087：基于原批次证明的只读质量观察

状态：基础观察已实现，生产质量闭环继续。

既有执行器持有窗口计数或主机分页回执，口径及迟到处理不同；直接累加最近记录会重复统计，主机回执也不足以反推转换通过率。

既有Java平台增加纯领域观察、只读应用服务和HTTP适配器。沿用租户事务及本人记录，固定版本后最多查询21批，返回20批和截断；单批UUID查询复用原证明。读服务无来源、输出、凭据、通知或动作端口，不重新执行计划，不新增数据库或启动单元。

以批次为统计边界，不生成跨重叠窗口总成功率。指标旧点重复提交和新增点分开，日志只发送新增位置；主机未保存分项为null。来源失败没有批次数量，读取时间和任务状态不代替连接、新鲜度或全源完整性。

在服务端检查租户、本人、工作流、来源元数据、目的及逐实体读取权限。公有观察不含原始行、实体ID、值、后台身份或凭据。行摘要/时间不一致时报错，不用查询条件隐藏损坏后返回空结果。

Web请求容器管理可信会话、取消、单次展开读取、显式刷新和UUID查询；纯展示组件展示逐批表格、原批关联及详情。403清理私有页面，隐藏/卸载取消在途读取，迟到响应不得跨身份落地；失败无自动重试。

专门异常计数、历史重放、UNKNOWN放弃、租约/fencing、生产容量与保留仍需各自协议及验收。见[计数契约](../../contracts/workflow-quality.md)、[使用说明](../runbooks/workflow-quality.md)及[实际验证](../VALIDATION-REPORT.md)。
