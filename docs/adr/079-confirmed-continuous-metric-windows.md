# ADR-079：固定指标流程的有界连续窗口

日期：2026-10-04。状态：已实现，验证见报告§117。

以下记录§117的初始60点策略；当前600点完整分页及上一分钟补采由[ADR-083](083-bounded-metric-pagination-and-late-points.md)扩展，不重写旧批次。

## 决策

既有Java平台运行固定发布的ZABBIX_METRIC→标准METRIC流程，不增加服务、数据库或执行框架。每次处理一个半开60秒窗口；首次从服务器受理时间前60秒开始，延后10秒读来源。后续窗口从确认checkpoint开始，不能在恢复时跳过失败或未知范围。上游固定指标项两次元数据核对之间读取history.get，按clock/ns升序、limit=61；第61点拒绝整窗，不截断推进。24小时前的待处理窗口拒绝，不能默默丢弃或改起点。

指标点只在本次内存与既有VictoriaMetrics中。V044只保留Task、不可变控制回执及每窗摘要：固定版本、时间、来源/映射系列、点时间戳、计数和批次digest；不保留数值、输入行、凭据或Principal。每组最多5条执行已有算子，整个窗口标准转换执行一次，不补造资产绑定；collection_mode=WINDOW_60S将持续系列和原样本系列区分。

先提交IN_FLIGHT摘要和pending标识，再尝试一次输出。连续输出在成功POST后仅等待5秒，再做一次精确值/标签回读；这是明确的有界确认阶段，无额外GET循环、POST重试或回退。仅整批匹配才确认并推进checkpoint。健康空窗或全过滤窗不写时序库，确认零点窗口；来源失败不当空窗。单点精度或毫秒冲突拒绝，不舍入覆盖。

失败分为明确输出拒绝与结果未知。明确拒绝后，显式RESUME可清除失败pending并重新读取同窗，旧失败证据保留。UNKNOWN与中断IN_FLIGHT只经原系列/原时间戳/digest核验，不重新读来源、不重发输出。核验成功后失败任务保持STOPPED；明确RESUME重新签发授权，从确认后的下一窗口开始。无法核验的未知范围保持可见且阻止恢复，自动放弃/跳过不在此阶段。

START只用于首次任务；STOP/RESUME使用期望代数、固定版本和原控制UUID。原键同内容返回不可变受理快照，不改变当前任务或续期；异内容409。每所有者20任务、200批次、180个启动/恢复回执、200控制总额为停止预留。开发会话最多20窗；OIDC后台还受既有最长15分钟/20批授权，每次重新核对可信租户、所有者、策略digest、来源对象与指标权限。源读取共享2并发，样本与持续输出共享2并发，禁止浏览器授予权限。

## 局限与后续

既有租户事务锁将本机输出与STOP串行化，网络读在journal事务外，再入场校验代数与固定pin。输出确认持锁有时延，停止可能等待或返回待确认；原控制回执查询处理这种情况。该锁与进程内并发门禁不等于HA租约/fencing，连接丢失后的旧执行器仍需后续S7处理。

10秒来源迟到容忍与5秒输出确认等待是当前有界策略，不是来源永不补写的证明；更迟到点、重叠回看、超过60点/分钟的完整分页、自动周期Host扫描、日志持久输出、版本依赖升级、保留/清理和生产容量继续。输出回读确认是可检索证据，不代表已验证进程/主机断电后的物理耐久性。
