# ADR-074：工作流的固定指标来源

日期：2026-10-04。状态：已实现受控单系列的只读预览、保存、发布与谱系查看；持久指标输出及后台执行继续。

标准指标目标需要读取来源原始值，才能在固定映射中执行一次归一化。新增ZABBIX_METRIC来源，绑定既有接入配置版本及服务器保存的指标发现记录。旧MANUAL_SAMPLE和ZABBIX_HOST保持原语义；ZABBIX_METRIC必须使用METRIC 1.1固定映射，不能绑定通用指标、日志或实体目标。

来源pin固定发现回执ID、itemId、hostId、完整来源键、原始单位、原始类型及摘要；配置和来源pin均进入工作流语义摘要、版本比较与运行元数据。系列由固定物理来源、主机及指标项标识；这不是已存在的MetricBinding，也不会给另一接入实例的旧绑定补造谱系。

只读选择接口仅查询服务器拥有的发现回执，最多检查最近20份、返回100项；没有上游读取、绑定创建或业务输出写入。选择要求未过期、真实来源、完成的固定配置发现记录及当前可用连接，验证分页父根谱系、完整映射和可信source/endpoint/credential/metric/entity对象范围。到期的发现不能作为新选择。已保存定义保留历史发现出处；历史出处不代替实时授权或当前来源一致性证明。

服务器执行预览前解析完整固定配置与出处，再经既有受控连接适配器执行item.get → history.get → item.get。只读取固定数值系列最近10分钟的最多6点，其中第6点仅检测截断，最多5点进入确定性计划。两个元数据读取均逐字段核对pin；主机、完整键、单位或类型变化返回SOURCE_CHANGED。时间、顺序、唯一性、类型、数值和容量在执行侧校验，没有任意地址、动态查询、隐藏重试或Fixture回退。原始value不提前归一化。

网络读取不占用工作流PG事务；并发沿用连接读取共享上限2。秘密版本在网络前后复核，保存回执前再次检查来源和目标依赖。失败不保存成功回执。预览与发布仍分开，发布不写时序数据、不启用任务；历史只保存状态、计数、原因及完整pin，不存原始值或标准结果正文。

前端复用接入/连接版本选择，并抽离WorkflowMetricSourcePicker请求容器与WorkflowMetricSourceList展示组件。可见且身份就绪时，每个固定配置首次读取一次；关闭、隐藏及身份变化取消请求，拒绝迟到结果。失败或取消后显式重新读取。当前标准映射必须精确匹配发现结果；绑定后不能悄悄换目标映射，需显式切回手工来源。完整键、单位、系列与摘要可查看，定义链接准确跳转。

没有增加启动单元、数据库、迁移或执行引擎。现有实体后台运行入口仍不接受该指标来源。下一阶段需单独交付可信可撤销后台委托、固定批次/checkpoint、幂等真实输出、停止/恢复与质量查询；本决策不宣布S5或生产门槛完成。
