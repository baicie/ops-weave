# ADR-061：可编辑转换图与固定版本运行

状态：已实施（限定本地开发实体运行）。2026-10-02，用户要求补齐拖入算子、手动连线、分支合流及运行。实际验证范围见VALIDATION-REPORT §89。

沿用四个启动单元、X6和Java确定性算子，不增加工作流引擎服务、数据库或任意脚本。编辑、版本发布和任务启停分别管理。

v2兼容既有单链，扩展为最多16节点、32边的有向无环图。SOURCE→MAP为固定入口，VALIDATE→OUTPUT为固定出口；普通处理节点只有一个输入，可以分流。MERGE显式合流，合并有效分支字段；同字段不同值拒绝并返回MERGE_CONFLICT，禁止隐式覆盖。过滤分支不进入合流；任一分支错误拒绝整条记录。节点必须全部可从输入到达且能到达输出，保存时拒绝孤立、环、重复和错误端点。草稿可暂时断线，保存/预览/发布始终由服务端重新校验。

前端定义和布局是唯一编辑状态；X6只展示和上报事件，不独立保存另一个流程。拖入、按钮添加、连线、删除、重排和撤销共用状态；可访问按钮和连接表单提供拖拽的替代入口。发布版本不可编辑，创建下一版后修改。

运行分为只读测试与显式实体写入。保存/预览/发布不自动启用；已发布ENTITY版本展开运行管理，指定来源稳定标识字段和实体名称字段。手工执行先取得15分钟内有效的已发布RUN测试回执，再以该回执UUID作为执行幂等键；服务端重查摘要、输入摘要、固定模型、完整批次和对象权限。重复键返回原执行回执，改变输入/配置拒绝，超时只能原键确认，不能隐藏重试。

实体写入使用独立workflow.<id>来源命名空间，按tenant/流程/模型/来源标识字段及值构造稳定ID，数值标识规范化；不按名称或IP猜测既有Zabbix实体。全批转换和对象授权通过后才开始写入，过滤不删除实体，不对账缺失。每条写入沿用库存事务和稳定Observation ID/时间。同批写入可能部分成功；回执只记录已确认ID和闭集错误，失败不自动重试。库存事务与工作流回执事务独立：回执提交失败可能已写入，客户端保留原执行键并显式确认。已知部分失败回执不会继续剩余写入，修正后新测试/新键执行。

持续任务仅在loopback、dev认证、PostgreSQL模式启用。调度器每5秒通过现有PrincipalResolver解析平台配置的可信开发身份，不存浏览器Token、不从任务构造tenant/用户/权限。生产OIDC后台委托尚未实现，接口返回不可用。已发布ZABBIX_HOST版本可显式启动/停止，任务固定revision/digest/settings；处理启动后新完成的已有Host批次，不发起采集、不回放历史。按completedAt/id游标读取最老待处理批次，失败/不完整/Raw缺失/截断/超过5条及授权撤销会持久标为FAILED。重启服务恢复RUNNING任务；失败需显式重新启动，重新启动从当前时刻开始。

任务控制使用expectedGeneration CAS。工作流PG租户级事务锁覆盖批次写入与任务停止，多进程竞争时重读generation/state；停止返回前等待先开始的批次完成，之后不能开始新写入。不是分布式租约工作流引擎，不提供并行分支执行、吞吐或HA承诺。共享运行并发2，每用户20个任务/200个执行回执，待处理批次最多50、每批最多5条。满额显式失败，不自动丢旧批次或清理回执。

V032保存任务与执行元数据（不保存样本/客户正文/凭据），V033扩展有界DAG测试trace预算，V034添加完成游标索引；按顺序升级。受限平台运行角色仅获task SELECT/INSERT/UPDATE和execution SELECT/INSERT。逆序人工回滚；先停任务并导出回执，trace超旧限额时回滚拒绝，禁止静默截断。日志/指标持续写入、关系输出、任意代码节点、通用HTTP和AI节点仍未实现。
