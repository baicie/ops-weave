# ADR-025：Web 公共请求层与开发凭据生命周期

日期：2026-09-25。状态：本机实现；M1 生产登录仍未完成。用户暂未准备外部身份/模型/来源配置，先完成可独立验收的客户端边界。

## 问题

六个业务页面各自携带 Token，重复实现 HTTP 读取和错误处理。切换页面需要重新输入凭据，大小/超时约束不一致；流水线页面在权限失效后可能留下已载入草稿与编辑内容。仅在某个页面清理状态无法保证公共认证生命周期。

## 决定

平台业务 API 使用一个 `JsonClient`，页面不再把 Token 作为业务函数参数。开发凭据由 `CredentialSession` 持有，同一文档内的 hash 导航可共用；模块栏提供明确的“清除开发会话”。没有 localStorage、sessionStorage、Cookie、URL 或普通日志中的凭据持久化。

凭据输入开始计算绝对 30 分钟的客户端保留期限，读取不会续期。到期、清除、替换、`pagehide` 会增加会话修订、取消在途请求，并清除已展示数据与客户编辑内容。刷新要重新输入。页面订阅在卸载时取消，页面自身仍管理操作顺序和已发起的幂等请求标识。

401 清除开发凭据；403 保留凭据供访问其他被授权资源，但清除全部当前页面数据、草稿和待确认表单。发起请求时捕获会话修订，旧请求的成功、失败或迟到 401 均不能影响新身份。错误状态由被拒请求的安全错误描述展示，不依赖服务器原始文字。UI 长度检查和此处的保留期限不是服务器认证规则。

历史 fixture Runtime 演示继续使用独立的页面凭据和 `/agent/api/v1/` 接口，不接收平台凭据；离开/替换凭据清除演示结果。平台当前知识诊断始终走 Java `/api/v1/` 同源入口。

## HTTP 边界

- 只接受所属同源 API 路径，禁止远端地址、路径越界、fragment、控制字符和重定向；不接收响应中的任意 URL 作为下一请求目标。
- `credentials: omit`、`mode: same-origin`、`redirect: error`、`cache: no-store`、`referrerPolicy: no-referrer`。当前 Java 是显式 Bearer 开发边界，未切换 Cookie，未实现生产 OIDC/CSRF。
- 请求 JSON 最多 64 KiB；响应流最多 2 MiB。AIInsight 继续保留更小的 128 KiB 上限。失败正文最多 8 KiB，只提取有界代码和扫描页数；401/403 直接按状态归一化，绝不显示原始响应/HTML。
- 共享至多 6 个在途请求，不排队重试；每次执行包含响应读取的显式期限，普通操作 15–35 秒，关联调整 20 秒，当前诊断最大 80 秒。取消后结束本地读取并释放资源；已完整读取的成功响应正常结束，不追加 abort。
- 流式计数字节、固定大小缓冲和严格 UTF-8/JSON；拒绝 Content-Length 超限、乱码、非 JSON 和不匹配的响应请求标识。没有状态错误到空数组或 fixture 的回退。

POST 的网络失败/超时可能发生在服务端提交之后。公共层不自动重试，页面沿用业务 requestKey/runId 查询或人工重试；客户端取消不等于服务器事务回滚。公共并发额度不替代 Java/Rust 的执行器预算。

## Java 与契约

`RequestBoundaryFilter` 为 `/api/` 成功和失败响应设置 `Cache-Control: no-store`、`Pragma: no-cache`、`X-Content-Type-Options: nosniff`。可选 `X-OpsWeave-Request-Id` 必须是单个 UUID；缺省生成，非法/重复返回 400，正常响应回传规范 UUID。OpenAPI 每条平台路径声明该可选参数和样例。

标识只用于关联请求，不能替代 Principal、tenant、资源权限或业务幂等键。过滤器把它放入请求属性及 MDC，并在 finally 恢复原 MDC；没有增加含正文、Authorization、URL 参数或客户内容的普通日志。它还不是跨服务追踪或持久审计系统。

## 验收与后续

检查与失败修复见 [验证报告第 31 节](../VALIDATION-REPORT.md)。覆盖平台导航/清除/刷新、401/403 清理、旧响应、大小/编码/时限/并发、fixture 凭据隔离，以及真实 Java 响应头。`pagehide` 处理有事件测试，不能宣称已通过所有浏览器 BFCache 场景。

这项工作完成公共客户端与开发生命周期，不能将开发 Token 宣称为生产登录。仍需生产 OIDC/BFF Cookie/CSRF、后端会话撤销与委托主体、完整资源筛选 URL 恢复；同时继续多源冲突历史与观测追溯。清除开发会话只删除该标签页的凭据和数据，不会撤销服务端配置的开发 Token，也不影响其他独立标签页。
