# ADR-070：有界来源指标元数据发现

状态：接受，2026-10-03。范围：现有平台接入实例的显式发现，不增加启动单元、数据库或持久运行引擎。

## 决策

在已有检查回执协议中增加 `DISCOVER_METRICS`，入口为 `POST /api/v2/data-sources/{id}/discover-metrics`。命令仍仅包含原请求 UUID、实例配置版本和连接摘要。身份来自可信认证边界，服务器校验本人实例、SOURCE_SYNC、物理来源对象范围及固定连接；浏览器不提交地址、凭据、租户、查询、游标或执行代码。真实来源要求完整配置及版本化凭据，旧环境引用需要先明确绑定地址与凭据。原请求重放、历史读取不重复上游操作。

真实读取通过既有数字地址登记和凭据解密边界，在读取前后核对固定版本与撤销状态，共享受控读取并发。仅执行两次固定 `item.get`，按 itemid 升序读取21项，包括一个分页哨兵，结果最多保留20项。只请求 itemid/hostid/key_/name/units/value_type，排除模板自身指标；不读 lastvalue、history、描述、脚本、密码、告警或完整资源。每次使用既有10秒交换超时、2MiB响应预算，无重试、任意参数、完整清单遍历或隐藏Fixture回退。

两次投影一致且无哨兵时，complete表示两次读取观察到的当前授权可见清单完整；它不证明来源拥有事务快照或来源角色能看见全部租户资源。有哨兵保留首20项并标为INCOMPLETE；两次不同标为UNVERIFIED/INCOMPLETE。失败为UNREACHABLE，不能当作完整空快照去删除资源。Fixture仅从现有不可变合成指标来源投影并标记LABELED_FIXTURE，真实失败不会走此路径。

保留来源完整键、名称、原单位、原类型及来源项/主机ID，不保存指标值。匹配现有配置的精确来源键时，附带标准指标完整键、映射id/revision/digest、单位、值类型与固定转换表达式。摘要覆盖该映射的完整配置，包括维度和验证范围；这里只是不可变观察依据，尚未成为工作流标准映射独立执行pin。没有配置、类型不匹配及未知类型明确保留，不自动生成定义或绑定。

复用PENDING→COMPLETED/UNKNOWN、65秒接受期限、15分钟有效期、主体200份回执和最近20份读取。CURRENT由服务器固定凭据及配置重检后判定，浏览器不因为真实来源模式而一概拒绝。过期、归档、配置变化、撤销或不完整结果不能显示为可复用成功。CURRENT也不授予下一次执行权限。

## 存储与兼容

来源检查新增可空metricDiscovery投影。旧Host回执可缺少此字段，读后规范化为null；新种类完成记录必须包含闭合指标投影。原检查命令摘要域保持，kind区分原请求，不能同键换成指标发现。V039把同一JSON回执的字节上限改为256KiB，容纳20项受限Unicode元数据；仍不保存第三方正文。迁移接入资源打包与启动迁移器，不手改旧迁移、不增加表或更换数据库。

## 前端

SourceInstancePanel继续持有授权、显式命令和未知结果恢复；SourceInspectionResults负责回执展示，SourceMetricDiscoveryResults只展示表格与精确定义链接，不请求网络。初次打开发现页签只读一次历史，不自动测试或发现。完整来源键与标准键换行；空来源单位显示“未声明单位”，不伪造平台单位。手机上验证单元格及链接自身不会溢出，明暗主题沿用项目变量。
