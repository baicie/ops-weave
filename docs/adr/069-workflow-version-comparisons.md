# ADR-069：已保存工作流版本的有界配置比较

状态：接受，2026-10-03。范围：现有四启动单元中的工作流元数据；不增加运行、调度、数据库或远程算子。

## 决策

提供只读 `POST /api/v1/integrations/workflows/comparisons`。请求仅包含同一流程的base与candidate，双方都固定id/revision/state/editVersion/digest。POST用于承载完整封闭引用，不是保存或执行命令。可信Principal来自原认证边界；SOURCE_SYNC、workflow范围、租户、本人草稿及双方来源对象范围均由服务器检查。拒绝query、未知属性、重复JSON键、伪造身份及超出既有64KiB输入预算的正文。

在同一WorkflowStore事务内读取双方保存版本；已发布版本租户可读，草稿仅作者可读。编辑号或语义摘要不同返回CONFLICT，布局更新引起的编辑号变化也冲突；缺失或他人草稿返回NOT_FOUND。读取旧来源配置只核对既有历史与对象范围，不要求其当前可执行，不读上游、秘密明文、输出数据或模型目录。保存定义中的固定来源/模型/算子摘要原样比较，失效依赖仍能显示；结果不能授予执行权限或证明兼容。

纯Java比较器产生确定顺序的扁平Changes，最多1200条；字段键最多96字符，前后值各最多4096字符，节点标识最多32字符。null表示未设置，与空字符串区分。比较流程名称、来源类别/实例/配置pin、输出类别/模型pin、节点增删与类型、算子版本/digest、字段映射与参数、连线增删及执行顺序。映射键、节点标识、参数值和摘要保留完整文本；不把JSON片段或HTML当作可执行内容。

不同revision自身、画布坐标、更新时间、编辑号与预览回执不列作处理配置变化；请求引用仍包含用于并发核对的revision/editVersion/digest。节点顺序影响执行；边集合相同时边序变化单列，保留合流输入顺序的语义。比较不创建预览、运行历史、审计业务正文或发布记录，不重算当前模型、不自动固定或升级旧版本。

## 交互与分层

版本列表提供“比较版本”；编辑器使用更多菜单，仅已保存且无本地修改时可打开。WorkflowComparisonPanel持有可信会话、选择、显式请求、刷新与取消；WorkflowComparisonDrawer只渲染版本选项和分组表格。非模态全高贴右抽屉，Esc/关闭回到可见入口；三宽度与明暗沿用统一变量。完整键与digest换行，不撑宽页面。

打开或切换选项不发比较请求；默认以所选项为对比版本，另一已发布版本为基准，单版本也允许明确比较自身。选项来自最近列表，截断需明确显示，不能宣称完整历史。冲突或失败保留错误，仅“刷新版本选项”读取新元数据，再由用户明确比较；没有自动重试、静默选新版本或Fixture回退。刷新后已消失选择置空，但仍允许再次刷新。关闭、切页或身份变化取消请求，迟到响应不恢复；403清空私有缓存和抽屉。

客户端核对响应双方精确引用、时间、封闭属性、变化类型/长度/节点范围和重复变化标识；显示服务端结果，不自行替代服务端授权或比较。

## 验证与后续

实际范围见验证报告§107。本决策补齐已保存配置差异及并发提示；标准映射独立版本pin、完整模型/指标发现、显式依赖升级计划与发布冲突、固定来源持久批次和可信后台委托、真实输出查询、质量恢复容量仍是后续工作。不是兼容性评估器或生产调度验收，M0–M4门槛不提升。
