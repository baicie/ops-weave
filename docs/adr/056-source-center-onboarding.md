# ADR-056 数据源中心与私有接入配置

日期：2026-09-28。状态：接受，OW-ST02第一段；不扩展启动单元。

## 决策

新增数据源中心，承接“选择类型→配置抽屉→确认→工作流画布”。当前来源能力是平台配置的一条Zabbix连接和手工JSON样本。CMDB快照保留已有导入页面，明确尚无画布配置。不得将多个接入方案显示成多个独立连接。

抽屉设置接入名称、说明、固定初始ENTITY模型id/revision/digest。Zabbix仅展示经来源授权的API地址、凭据引用名和模式，支持显式只读连接测试；浏览器不能提交新URL、凭据值、租户、主体或权限。增加/轮换平台连接仍由现有部署配置完成，尚无多实例或密钥管理系统。

确认在同一WorkflowStore事务保存私有SourceSetup与第一版工作流草稿。requestId由浏览器为一次确认生成；tenant/subject来自可信认证。相同请求和内容返回原记录，变化返回冲突；连接配置摘要或目标模型变化失败关闭。PG复用租户事务锁，设置容量200份配置/人、50份活动草稿/人，列表返回最近20份并标记截断。

配置是不可变创建快照，不是启用中的采集绑定。持久保存创建时fixture/zabbix-jsonrpc/MANUAL_SAMPLE标记和摘要，避免后来配置切换洗掉Fixture来源。摘要覆盖模式、来源、模型及用户配置；连接摘要覆盖地址与凭据引用，**不包含密钥值，也不代表凭据值轮换已被版本化**。配置不存样本、原始厂商数据或模型正文。

默认创建SOURCE→MAP→TRIM→VALIDATE→OUTPUT。未知自定义字段的初始映射只是建议，须在画布用样本检查。确认不扫描来源、不执行工作流、不写资产、不调用模型。测试连接仅探测版本并保存自检回执；连通性成功不等于完整采集兼容验收。

跳转URL只携带workflow id/revision/state；读取仍需可信会话。配置继续编排打开第一版当前草稿或其不可变发布版本；后续版本从工作流页面明确创建，配置不会自动跟随。客户端拒绝异常链接，切换会话中止请求并清空私有数据，未知提交结果固定原命令供显式查询/重试，无隐式重试。

## 尚未实现

多实例地址/凭据编辑、来源配置版本生命周期、测试门禁后启用采集、工作流与采集的运行绑定、自定义实体/关系实例写入、分支循环/脚本、AI协助及动作执行。原v1 Host流水线、Zabbix版本适配和只读诊断边界保持不变。OW-ST02及M0–M4不因此全部关闭。
