# ADR-068：静态工作流算子目录与固定语义摘要

状态：接受，2026-10-03。对应范围：现有 v2 有界转换 DAG 的目录、编译和发布依赖。

## 决策

算子元数据唯一源是 `contracts/catalog/opsweave-transform-operators-1.0.0.json`。当前登记11个内置类型、版本1，包括输入、映射、校验、输出和7个可添加处理节点。目录包含固定实现标识、参数类别、输入/输出类型与连接数、显示名称和摘要；不能提供类名、下载地址、脚本或网络工具。Python生成器仅在开发/CI同步纯Java静态描述、TypeScript元数据及Node配置Schema，不是执行后端。

摘要使用UTF-8字节长度前缀的SHA-256，覆盖类型、版本、固定实现标识、配置类别、有序参数与端口。显示名称、说明和分组不改变执行摘要。`implementation`是受审查的内置语义版本标识，**不是二进制文件或源码内容的哈希**；改变执行语义必须登记新版本并保留所需旧实现，不能仅修改同名处理器。当前二进制仅支持版本1，未知版本/不匹配摘要不能执行。没有动态加载、下载、缓存授权或新增服务。

`Node.operatorDigest`为兼容历史可缺省；存在时参与Definition语义摘要，不能为null。新发布必须每个节点都有匹配当前登记实现的pin；布局变动不影响摘要。保存/执行验证已提供pin，执行在来源读取前解析所有算子和输出模型。每次评估编译一个最多16节点/32边的纯内存计划，预先解析父节点和固定端口，逐行使用同一计划；没有逐指标点持久编排或新增数据库。现有单条32字段/4096字节、最多5条预览、共享并发及身份/来源复核继续生效。

端口类型是`RECORD_V1`与`VALIDATED_RECORD_V1`，固定`in/out`标识；输入无入口、输出无出口、校验输出只接有效记录出口。普通节点单输入，MERGE保留旧的至少1输入和冲突拒绝语义，最多16输入。目录提供约束，实际执行仍由Java内置穷举处理器实现；目录文字不能授予Tool、来源或输出权限。

## 兼容与交互

旧pinless不可变版本继续只读和执行原有版本1，GET不迁移或改写PG数据，原摘要/回执保持。旧草稿可以查看、保存与预览，但不能新发布；更多操作中的“固定算子版本”明确修改内存Definition，支持撤销/重做。保存后原预览失效，需重新预览并通过原15分钟、CAS和来源门禁。旧已发布版本的原请求重放保留既有幂等返回；新版本必须完整pin。

服务器在授权工作流工作区响应中附带闭合目录，不增加首次自动列表请求。客户端与已生成的本版本目录核对；不兼容目录报错，不静默改用本地目录。缺失目录的旧响应允许历史查看，禁止新创建、升级和发布；失败只显式刷新。新模板和新节点使用读取到的目录pin，不自动升级已加载旧草稿；来源确认生成的新初版使用服务端内置pin，历史确认回执不重建。

## 验证与后续

实际检查见验证报告§105。下一阶段仍包括模型/指标发现与标准映射版本、完整依赖差异和升级冲突、固定来源的可信后台委托与持久批次谱系、真实输出、质量/恢复/容量和多副本验收。当前计划不是持久调度器，不扩大旧LOCAL_DEV_ENTITY实际运行范围，M0–M4退出门槛不改变。
