# 来源采样映射维护

入口：模型中心 → 指标定义 → 来源绑定。需要有权读取指标、实体及对应来源；维护还需要该来源的source.sync和source.configure。列表只代表当前授权范围的最多20份绑定，截断不表示完整库存。

1. 首次打开抽屉自动读取一次。查看完整指标标识、物理来源/监控项及固定状态；点击维护映射或查看映射读取当前绑定。
2. 核对完整来源键、标准指标键、当前绑定版本、选定映射id/revision/digest、转换、范围和维度。“查看指标定义”进入准确指标定义，不执行采集。
3. 旧绑定显示未固定。选择兼容的登记定义后点击确认固定映射；后续同id更高版本使用确认更新映射。同一已固定pin不再提交，目录失配不自动替换。
4. 提交使用当时绑定版本。结果待确认时保留原UUID，使用查询原映射请求；不要通过新UUID或刷新重复提交。原回执核对后才解除门禁。
5. 明确版本冲突时使用读取最新绑定，再核对规则。刷新来源绑定不会访问上游，也不会补采或修改其他绑定。

V040迁移保留旧绑定为未固定，普通同步不会自动采用部署中的定义。真实历史读取要求完整pin；上线前应在受控环境核对并显式固定需要继续采样的旧绑定。若目录的同id/同revision改过语义，必须修正登记版本及兼容策略，不能改数据库或跳过pin检查。固定变更用于后续读取，不把旧指标点重新标成经过本次完整摘要证明。

平台启动加载现有登记映射，目录缺失或重复标识失败。规则升级需提供新的登记版本；当前界面不创建任意公式。每主体维护回执200份上限，没有自动清理。单项读取支持已知来源/监控项，列表完整翻页尚未实现。

本机实际三项绑定、原回执回读/重复命令及真实只读历史已验证，见[验证报告第110节](../VALIDATION-REPORT.md)。这不代表标准指标工作流、可信后台委托、固定批次及质量恢复已完成。公开协议见[维护契约](../../contracts/metric-mapping-maintenance.md)，设计见[ADR-072](../adr/072-explicit-metric-mapping-pins.md)。
