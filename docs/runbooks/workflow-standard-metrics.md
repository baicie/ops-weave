# 使用标准指标映射

进入“数据接入 → 数据工作流”，新建指标样本模板。点击指标输出节点打开右侧配置抽屉，在“指标定义”中选择完整名称及固定版本；也可保留通用GAUGE格式。

标准定义显示完整来源键、转换、单位、类型、范围和固定维度。完整指标名可打开具体指标定义，映射摘要按需展开。更换定义会重建字段映射和处理链、清除旧预览；撤销可以恢复原有节点和连线，已发布版本只能查看或创建下一版。

映射节点需要timestamp、sourceKey、value三个来源字段。sourceKey必须是目录里的精确键，value填来源原始值。例如CPU user来源的12.5经multiply:0.01转为标准值0.125，单位1，固定维度mode=user。不要提前把原值乘一次后再进入同一标准映射。

展开“测试数据与结果”，可明确点击“填入 Fixture 指标示例”，或填写自己的合成JSON样本。示例不会自动替换已有内容，也不会随草稿保存。保存、预览后查看校验和输出节点；标准结果包含完整映射pin，数值是精确十进制字符串。错误来源键、类型、时间或越界值会拒绝，拒绝记录不能发布。

目录中的固定版本缺失或不兼容时仍可查看原定义及完整摘要，但不能预览；选择当前可用定义需重新保存和校验。浏览器不自动换成最新版本，也不自动刷新或重试写请求。

标准指标流程支持手工样本与[固定真实指标来源](workflow-metric-sources.md)的只读预览和不可变版本管理，发布不会写指标点或启动采集。固定来源已明确系列与元数据出处，[有界样本输出](workflow-metric-output.md)已实现，持续完整批次/checkpoint仍在后续阶段；Zabbix Host批次继续仅供实体工作流。完整操作见[数据工作流](workflows.md)，边界见[ADR-073](../adr/073-standard-metric-workflow-targets.md)及[ADR-074](../adr/074-fixed-metric-workflow-sources.md)。
