# 查看运行质量

在已发布的主机、固定标准指标或日志来源工作流中展开“运行质量与异常”。首次展开自动读取一次，按需刷新，失败不循环读取。显示此版本本人最近20批；更多历史可用完整批次UUID查询。

点击批次查看窗口/分页范围、确认/未知/待确认、原批次和迟到分项。确认率以本批预期输出为分母；“—”表示缺失或0，不代表0%或100%。主机没有完整转换分项，保留“—”。质量页不核验、重放或写入。

指标补采会重交旧点，日志补采只写新增位置；不要将最近批次输入相加当成新增流量。读取时间只说明何时读到元数据，任务停止或批次确认不说明连接当前可用、数据最新或全源完整。

任务错误在任务控制入口处理。读取失败没有批次时保留错误，不能视作健康空窗口；健康空窗口有CONFIRMED的0条证明。403清理页面与会话，重新认证后才能读取。

批次质量复用原PG证明，独立检查统计使用V049元数据表。损坏元数据返回503，应保留证据调查；不要删除UNKNOWN、重发输出或篡改确认。节点测试问题在运行详情；持续指标/日志另见[检查统计](workflow-diagnostics.md)的逐次异常与未知量。主机细分、排队统计、告警、历史修订、保留和生产容量继续。详见[质量契约](../../contracts/workflow-quality.md)。

旧日志批次缺少明确未写入证据时（§130），预期记录数显示为未知，拒绝/确认均为0。原任务保持暂停，显式终止恢复之后任务显示已终止恢复，批次仍未知；查看现存日志也不改变原证明。原UUID详情使用同一观察规则。质量读取没有来源/输出调用，数据缺失不能按0成功处理。
