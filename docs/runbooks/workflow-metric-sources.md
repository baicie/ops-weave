# 选择固定指标来源

在来源中心打开已维护的Zabbix接入，选择固定连接版本并显式“发现指标”。发现成功后可查看完整来源键、原始类型/单位及标准映射。只支持当前登记的数值GAUGE标准映射，不把未映射项目猜成平台指标。

在数据工作流创建指标模板，先于输出节点选择相应的完整标准指标与固定映射。点击数据输入节点，在右侧抽屉“选择接入实例”，选择实例和固定连接版本；页面自动读取一次可用发现清单。选择系列、核对主机/指标项和完整键后点击“使用此指标来源”。这一步只修改本地草稿。

没有匹配项时，回来源中心对该配置发现指标。失败、过期或取消后不会自动读取上游；“重新读取指标清单”只读现有发现记录，过期需要先重新发现。已保存版本保留原出处和摘要，不能用新发现悄悄替换旧来源。

保存草稿，再预览。来源读取最近10分钟最多5个原始采样点，另读第6点检测截断；标准映射执行一次数值转换。CPU user原值12.5按multiply:0.01生成0.125，不能先在来源中乘一次。当前真实来源不显示手工样本输入；绑定后更换标准映射需要先显式切回手工来源。

主机、完整键、类型或单位变化会拒绝预览；连接不可用保持失败。不要把失败当空来源，也不要反复提交未知结果。成功后可以发布不可变版本；发布不写指标点或启动任务。运行记录可按原回执查看完整来源键、系列、配置版本与元数据摘要；显示来源读入数量和参与转换数量，不保存原始值。

[有界指标样本输出](workflow-metric-output.md)已实现；固定配置后台批次/checkpoint及停止恢复仍在实施。既有实体运行入口不接受固定指标来源。设计见[ADR-074](../adr/074-fixed-metric-workflow-sources.md)，结构与预算见[契约](../../contracts/workflow-metric-sources.md)，标准转换见[指标映射](workflow-standard-metrics.md)。
