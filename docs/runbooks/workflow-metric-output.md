# 指标样本写入与结果确认

打开已发布的固定 Zabbix 指标工作流，展开“指标输出与回读”。面板第一次打开自动读取能力和最近记录；失败后使用“刷新记录”显式重读。核对完整来源键、完整标准指标及固定版本；指标链接进入定义详情。

点击“写入样本”会受控读取该系列最近10分钟最多5条原值，按固定工作流转换后发起一次写入。此入口不是持续采集。只有完整批次在时序库中回读且摘要匹配才显示已确认；数量区分确认、失败、未知、过滤和毫秒合并。

结果待确认时保留完整请求 UUID，可先“查询原回执”，再“验证批次”。验证只查询原系列和时间戳，没有新写入。部分到达、点已过保留期、服务不可用或值不匹配都保留未知。需要查看当前数值时点击“回读指标点”，核对本次查询时间、实际/预计数量及完整批次匹配状态。

原回执明确404且当前页面仍保有原命令时才出现“重发原请求”；内容和 UUID 保持，不再读取来源。选择“放弃本次确认”只放弃页面锁定，不取消服务端。刷新页面后从最近记录选择未知批次可验证和回读；原样本不在浏览器持久存储或 PG 回执中，重载后不能重发已丢失的原命令。不要靠建立新请求掩盖旧请求的未知结果。

身份切换或权限拒绝清除私有页面内容。原历史结果仍须当前来源/指标范围权限；凭据撤销不会把已确认输出改成失败，新写入需要重新通过来源有效性检查。

本机需既有PG及可信配置的loopback VictoriaMetrics，使用1ms去重/时间精度与非流式Influx写入。配置不合格在POST前拒绝；真实端口失败保留错误。V042只保存批次证据，数据点留在时序库。200份 owner 记录满额后不再受理新写入；当前没有自动删除记录。

回退 SQL 位于 db/rollback/platform/V042__workflow_metric_output.sql，尚未实际演练。删除回执不会删除时序点，也会丢失原请求确认依据；回退前需单独保存证据和评估。生产独立角色、容量、HA租约/fencing及备份未验证。
