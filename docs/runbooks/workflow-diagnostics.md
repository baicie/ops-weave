# 查看工作流检查统计

第132节的来源失败统计与转换记录分母分开显示，旧记录未实测时保持“—”，详见[来源读取说明](workflow-source-diagnostics.md)。

在已发布的持续指标、持续日志或固定连接主机工作流中展开“运行质量与异常”，再展开“检查统计”。首次展开读取一次；刷新检查或输入完整检查UUID进行查询，不会启动来源、写入或重放。点击检查时间查看节点明细。表格在窄屏内横向滚动，键盘可聚焦表格滚动区域。

主机按“本次来源分页”展示，每页最多5条，单位异常保持“—”。例如前页5条通过、末页1条拒绝：前页的原确认仍保留，末页不会输出或推进检查点；不能把前页通过理解为整个扫描成功。正常记录可查看关联原批次UUID；拒绝发生在准入前没有关联批次。实体范围缩小后，无权读取任一来源实体时不能看到该页统计，包括随后过滤掉的实体。UNKNOWN显式恢复继续原分页，原统计不重复生成。

输入10、通过4、拒绝1、未检查5表示第一组5条已执行，剩余5条没有完成处置；不会生成该失败窗口的输出批次，也不会推进checkpoint。结构不符、缺少标识、时间和单位异常可能重叠，不按其和推断总拒绝量。节点跳过表示该行未进入后续节点，与未检查的整行数量不同。

来源失败或者来源端口直接拒绝样本时，没有完整列表分母，输入和节点数量显示“—”。健康空读取显示0；采样率、排队时间和日志单位异常尚未测量。转换检查通过也不等于写入确认，输出状态继续看批次质量和原始确认记录。

关闭、隐藏页或清理会话取消请求；403清理私有页面数据。读取错误不会自动重试。200条本人检查容量耗尽时任务暂停，当前没有自动删除或轮转；先审查原证据和任务错误，不通过删除或恢复绕过容量。FAILED任务已经暂停，STOP只对运行任务有效，修正后明确恢复需遵守原控制协议。

V049回滚脚本只删除新检查表。需要保留的统计先按本机管理流程导出；回滚前停用新生产者并退回匹配应用版本，不能在仍运行的新应用下直接回滚。隔离Schema已实际验证迁移、回滚和重新迁移，不代表已在主环境执行删除。原发布版本、输出证明和检查点不由此表管理。
