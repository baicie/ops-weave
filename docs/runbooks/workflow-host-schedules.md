# 周期主机采集

在已发布固定主机工作流打开“周期主机采集”。选择实体名称字段和1、5或15分钟间隔，启用后立即扫描；每轮完成再等待间隔。停止同时终止当前扫描和后续周期。

首次显示默认读取一次状态。启用时每5秒只读刷新；请求失败停止自动读取，可明确刷新。身份变化清理私有状态并忽略旧响应。控制结果不明保留原UUID和请求体、阻止页面关闭与后续写操作；先查询原周期回执。仅在404后允许按原请求重发或放弃本次确认。放弃确认不会取消服务器命令。

“已完成轮数”和“已确认条数”只包含整轮完成的扫描；当前部分进度查看“执行与任务管理”的资产批次。最近完成时间不代表原始数据同一时刻的一致快照。未完成扫描、来源失败或UNKNOWN不会作为完整空快照删除资产。

每次启用或恢复最多20批。委托模式还受最长15分钟的原授权有效期限制，自动采集不续权；过期、撤权或额度耗尽后明确恢复。恢复未完成扫描使用原行、原观察时间、原批次编号及原游标。若任务已被其他控制改变，先读取当前固定版本；周期不得接管它。

停止后的已完成周期可修改间隔/名称字段再启用新的扫描；未完成扫描需使用原设置恢复。普通单次扫描不能抢占已启用周期，手动停止正在运行的单次扫描也会停止关联周期。

实现复用现有Java平台、四启动单元和PG。适配器重建、协议Fixture和真实本机两轮采集的实际结果见[验证报告](../VALIDATION-REPORT.md)。当前不代表生产IdP、多副本租约、fencing或断电耐久性验收。
