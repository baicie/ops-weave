# 工作流运行记录

打开运行记录页，会话就绪后读取授权版本目录一次，再读取默认固定来源发布版本的已记录检查。可选明确版本，点击“加载更早记录”取同一快照的下一页；每页20条，沿用原本人200条检查容量。固定链接使用`#/integrations/workflows/runs?workflowId=<id>&revision=<revision>`，缺失或非法版本不选择最新版本替代。

列表显示来源与转换检查时间、UUID、失败/尝试、转换数量和实测本地排队。未测量显示“—”，通过数不表示写入确认。点击节点明细查看原窗口/分页、来源统计、调度时间及逐节点数量；输出状态需查看关联批次的质量证明。旧缺失数据不回填。

“预览与版本测试”保留原最近20条及UUID回查。`runId`直链继续打开对应预览详情。切换已加载视图、明暗主题或尺寸不再读取；来源/输出执行不会因进入记录页触发。

更多页失败保留已显示只读快照。409表示到期或选择失效，明确刷新后建立新快照；404游标失效也需刷新；403清理当前私有会话。记录与游标只在内存，关闭/隐藏/身份变化取消未完成读取，迟到返回不重新填入页面。目录截断不代表所有发布版本均已列出。

部署先应用V055并同步API/Web。`OPSWEAVE_HISTORY_CURSOR_KEY_REF=env:NAME`仅引用受控环境变量，其值为规范Base64的32字节密钥；勿放入请求、文档、日志或仓库。生产未配置/显式无效引用导致此接口503。未配置引用的开发模式使用进程随机密钥，服务重启后旧快照游标需刷新。密钥轮换同样令旧令牌失效，没有隐藏重试。

回退V055前需停止依赖序号的新版API并评审部署；回退仅移除新增列，保留观察正文与时间。随机隔离schema的前进/回退检查不授权回退主环境。

本节没有提供执行重放、通知、自动留存清理或生产容量承诺，完整目标继续。见[协议](../../contracts/workflow-history.md)、[ADR-097](../adr/097-scoped-recorded-workflow-history.md)及[验证报告](../VALIDATION-REPORT.md)第135节。
