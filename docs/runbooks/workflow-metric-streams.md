# 固定指标持续采集

打开已发布的固定指标流程，展开“持续采集”。首次可见自动读取状态；开始后显示确认至的时间、累计窗口/点数、本次额度和最近窗口。标准指标显示完整名称，可打开具体定义。指标样本输出保留独立入口。

首次“开始采集”由服务器选择最近60秒窗口，等待10秒来源稳定后处理。后续从最后确认时间连续推进。每窗最多600条来源记录，完整分页，单窗最多20次历史请求/20秒读取预算；超限或任何页失败时保留原窗口，不写入成功前缀。当前只支持标准固定指标项，不将指标目录记录数冒充采集种类或输出资产绑定。

下一窗到达稳定期后先回看上一分钟。新增点显示为独立“迟到补采”，摘要中可查看原批次；确认后点数增加，窗口数和确认至时间保持，下一次调度继续新窗。补采也消耗本次20批额度。已有点消失或值变化时暂停并显示SOURCE_WINDOW_CHANGED，不自动覆盖；恢复仍会检查原范围，需先解决来源修订问题。仅覆盖最近已确认的一分钟，停止或到期后不继续回看，更早迟到数据需要后续受控修复。

“停止采集”保留checkpoint；“恢复采集”沿用原版本、窗口和新限时授权，不重置时间起点。OIDC最长15分钟/20批，注销后后台独立运行，可重新登录停止。开发任务也最多20批。额度到期不自动续期，需明确恢复。

结果未知时先“核验原批次”。核验只读原时序范围；完整摘要匹配后确认并保持停止，再明确恢复。尚未匹配时不能重发或跳过该窗。明确输出拒绝可恢复后重新读同窗，旧失败批次仍保留。来源失败不会产生成功空窗；健康空窗会记录0点且确认范围。

控制响应丢失时保留原UUID/内容，查询原控制回执；原404后才可重发原控制请求。回执只说明原操作受理，当前运行状态另行读取。放弃本次浏览器确认不会取消服务器操作。失败或契约异常停止自动刷新，显式刷新才重试；身份改变清理私有缓存与迟到请求。

连续输出使用固定WINDOW_60S系列，成功提交后等待5秒，再做一次完整回读；仍不可见或不匹配保留UNKNOWN，不自动循环。批次查询只展示元数据，实际点值留在时序库。当前确认不是掉电耐久性、分布式HA或生产负载验收。
