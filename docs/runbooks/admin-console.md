# 运维管理控制台

界面使用仓库现有 React + shadcn/ui，工作区参考 shadcn-admin，导航与数据接入采用本项目共用布局。组件和视觉规则见[前端规范](../development/frontend-guidelines.md)。启动方式见[开发服务管理器](dev-manager.md)，Web 默认在 `http://127.0.0.1:5173/#/start`。

顶部按“工具栏 → 页签 → 面包屑 → 页面内容”排列，标准布局省略页签。搜索位于工具栏左侧，主题与布局设置位于右侧；当前位置在页签下方，和内容容器对齐。页面滚动时工具栏、页签及面包屑保持可见，面包屑随当前页切换。

## 运维工作台

- Go管理器启动的本地平台预览自动建立会话，无需填写开发Token；刷新会重新建立会话并清理旧数据。仅短时本地会话nonce留在标签页内存，实际开发Token留在服务端。明确启用OIDC时仍需登录，手动开发模式可显式选择，见[本地会话](local-session.md)。
- 点击“读取概览”发起两条已有 GET：资产分页和故障分页，各最多25条，首次进入或切换标签不自动读取。共享传输层仍检查会话、响应大小和请求范围；概览额外限制15秒，无自动重试。
- 四张卡片展示本页资产、本页ACTIVE资产、本页故障、本页OPEN/INVESTIGATING故障。它们不是全平台总数；存在后续游标时提示还有后续页。读取时间是浏览器收到本轮结果的时间，不是来源观测时间。
- 故障表展示当前页按创建时间排序的前5条，点击标题只恢复事件选择，进入后仍需显式读取详情。资产生命周期图仅计算当前页，不将缺失数据推断为健康；含Fixture资产时明确标记。
- 一项接口失败时，该项保持“—”并显示错误；另一项成功的数据仍按查询范围展示。401/403、改变会话或清除凭据会取消请求并移除旧结果，迟到响应不能重新显示。
- “接入指南”介绍配置、编排、检查结果的入口。创建接入配置或发布工作流不会自动启动采集；运行保留既有只读边界。

## 导航和页面

产品导航当前显示15个入口、6个分组；“接入维护”及其三个入口暂从导航和搜索隐藏，旧直接地址与服务端权限保留。未接入的诊断技能、AI执行记录及占位组件已移除。Fixture诊断仍供开发检查使用，但不进入产品导航或页面搜索。失效或未知地址回到工作台。侧栏支持分组、当前页标记和桌面收起；手机使用独立导航抽屉。页面搜索只搜索导航信息，Ctrl/⌘+K打开，方向键选择，Enter跳转，Esc关闭。主题与布局偏好分别保存 `opsweave.ui.theme`、`opsweave.ui.layout`，不保存Token、页面地址或业务数据。

模型中心的实体、关系、指标目录在会话就绪后由当前页自动读取一次，保留刷新/失败重试；指标为紧凑列表，名称及完整指标标识可打开定义。详见[模型中心操作](model-catalog.md)。目录定义不代表实时采样或启用采集。

桌面侧栏采用浅蓝灰底色，分类有图标，子页面以文字展示，当前页为蓝色底。底部“收起导航”切换为64px分类图标栏；悬停或点击分类打开页面浮层，方向键进入，Tab选择，Esc关闭并返回分类。点击外部或改变窗口尺寸关闭浮层。底部“展开导航”恢复原分组；进入新页面时自动展开所属分类。手机顶部“切换导航”打开独立抽屉，点击页面或Esc关闭并返回按钮。顶部工具栏提供页面搜索、主题、布局和本地开发/受控会话标记，当前位置在独立面包屑展示。

数据列表、统计卡片、表单、空状态和图形工作区共享颜色与容器规则。“使用说明”位于页面下方，不占用主操作区。模型、来源、事件、采集与工作流保持各自协议。“使用说明”的用途和长步骤只在展开时显示。AI留存默认显示预览入口，策略说明、回执查询按需展开；结果未确认时仍自动提供原请求回执查询，清理确认边界不变。

## 页面容器和多页签

工具栏、页签栏、面包屑和底栏保持固定，业务内容在统一容器中滚动。点击右上“布局设置”选择“标准布局”或“多页签布局”；主题按钮继续切换浅色/深色，两种布局都可用。

新标签页默认标准布局，导航只保留当前页面。启用多页签后，侧栏、页面搜索和页面内链接会打开或激活对应页签，每种页面最多一份；切换保留工作流/流水线编辑、未应用筛选和各自滚动位置。已经打开的页面从侧栏再次进入，会恢复它记住的查询地址。切回标准布局只收起页签条，原编辑仍可在再次切换后找回。

页签的×关闭页面，右侧“页签操作”提供关闭其他和关闭所有。存在未保存编辑时先确认，默认保留；请求正在处理或结果待确认时暂时不能关闭，应先完成原回执查询。最后一个页签关闭后显示新工作台。键盘方向键/Home/End切换，Delete请求关闭，Esc取消确认。

通过浏览器返回离开配置抽屉时，抽屉暂停展示，当前页仍能操作；返回该页签后恢复抽屉与原字段。暂停展示不取消正在执行的请求，也不放弃本地编辑。

这些页签属于当前浏览器标签页的内存。刷新只保留布局偏好和当前浏览器地址，不恢复未保存正文或旧页签列表。更换身份、注销或权限失效会清理后台页面，当前页仍清理私有结果并取消旧请求。当前19个已登记页面为缓存上限，没有任意网址页签或页面触发的后台自动执行。新增业务模块的步骤见[新增能力](../development/adding-a-capability.md)。

## 验证边界

浏览器回归使用显式HTTP Fixture；它不证明已连接真实来源、生产身份或模型。后台界面初版结果见 VALIDATION-REPORT §77，导航删减、流程/版本分层及自动读取增量见§81。

来源与工作流的紧凑布局增量见§82；§83将同一间距、字号、细边框与内容层次应用到全部18个产品页面，包括模型、资产、指标、故障、记录和维护表单。共用页头、内容区、查询工具栏及统计卡在 `components/PageLayout.tsx`，视觉规则在 `styles/console.css`。业务页继续负责请求、状态和操作门禁；统计明确当前查询页/列表，不将未读取或无数据显示为健康。三种宽度及明暗主题回归见§83，开发约定见[前端开发规范](../development/frontend-guidelines.md)。

## 来源与工作流

来源中心按“接入类型 → 我的接入”组织，工作流按“处理流程 → 数据流版本 → 编辑”组织。卡片和表格支持当前列表搜索及分类筛选，来源抽屉只配置来源，工作流默认直接进入画布，输出类型与目标模型在输出节点配置。紧凑节点、细连线、左右对应的字段映射、按需展开的测试结果和错误原因沿用同一主题，390px下可完成相同步骤。遥测不需要实体模型；Zabbix Host不提供日志/指标样本。界面明确标记仅转换预览，持续采集和存储仍待接通。见[工作流说明](workflows.md)及VALIDATION-REPORT §81。

来源卡片的图标、标题、已保存数量集中在顶部，分类与能力说明位于下方。流程名称、版本状态及保存/预览/发布集中在工具栏；下方以画布为主，右侧配置当前节点，输出类型与模型放在输出节点，手机上下排列。当前步骤使用蓝色边框和浅色背景，样本与结果保持按需展开。实现与实际验证见VALIDATION-REPORT §84。
