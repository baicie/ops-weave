# 为处理流程选择连接版本

先在接入实例中保存登记地址、凭据和明确的秘密版本。已有旧环境来源仍可按原批次方式使用，不会自动转换。

1. 打开工作流的“数据输入”节点，在右侧配置抽屉点“选择接入实例”。
2. 选择本人可读的主机实例，再明确选择配置版本。未保存完整地址/凭据的旧实例会显示尚无固定配置。
3. 核对登记地址与完整凭据/秘密版本标识，点“使用此版本”，保存工作流。
4. 点预览。固定来源不填写旧采集批次ID，也不接受手工数据；最多5条，只读。缺失、失败和截断按实际结果展示。
5. 合格预览后显式发布。发布保存固定版本，不启动持续采集，也不跟随新连接配置自动更新。

轮换凭据或接入配置不会更新已有流程。要使用新版本，创建下一工作流版本并重新选择、保存、预览和发布。撤销秘密版本、归档实例或移除/改动登记地址后，新预览与发布会失败；已保存的版本和审计元数据仍可在授权范围内查看。

连接列表失败只点“重新读取连接”重试。关闭/切换页面会取消只读请求，身份失效清理缓存；不会偷偷重新提交预览、发布或改用另一个版本。

当前固定来源支持配置到只读预览/发布。持续任务与真实写入需要后续可信后台授权和持久采集谱系，旧运行接口对此返回不可用。实际验证范围见验证报告第104节，不能用Fixture浏览器测试证明上游生产连接或持续任务已接通。
