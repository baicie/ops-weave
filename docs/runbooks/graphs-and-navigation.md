# 画布、关系图与页面入口

§89工作流增量：算子库支持拖入与按钮添加，端口可连线/删线，连接表单提供键盘替代入口；显式MERGE支持分支合流，环、孤立节点和普通节点多输入不能保存。发布版本只读；已发布ENTITY可展开运行管理显式写入与启停本地任务，不自动发起采集。步骤/图形和运行展示组件已抽离，详见[工作流说明](workflows.md)与[ADR-061](../adr/061-editable-transform-graphs-and-runtime.md)。下文§74单链限制是当时的历史范围。

从“工作台 → 运维工作台”进入。概览显式读取当前授权范围的第一页资产与故障；“接入指南”按“选择数据源 → 数据工作流 → 工作流运行记录”介绍配置和测试。页面下方“使用说明”解释用途、步骤与相关入口。布局与数据范围见[运维控制台](admin-console.md)。

- 数据源中心：选类型，在抽屉保存来源，直接准备未保存的本地工作流；输出类型由输出节点配置。
- 数据工作流：默认X6画布，点击节点在右侧配置参数，也可切换编号步骤。测试数据和工作流库按需展开。拖动只改变位置；上移/下移改变单链执行顺序。拖空白平移，普通滚轮滚动页面，Ctrl/⌘+滚轮缩放，适应按钮显示全部节点。保存、预览通过后发布固定版本，已发布版本只读。
- 工作流运行记录：查询转换成功/失败/过滤和节点错误；和Zabbix的采集运行记录不同。
- 实体模型/关系模型：定义结构和端点，不代表实体或关系实例已产生。关系模型内G6示意来自已发布目录。
- 资产关系图：读取资产，选择起点；G6展示受权且当前有效的直接关系。点击节点或下方列表查看详情，明细表展示方向、类型和来源。超过50条时提示截断，空图不补造关系。
- 接入维护：该分组暂从导航和搜索隐藏；Host采集维护、CMDB快照导入、资产绑定纠错保留原直接地址及各自授权、预览确认协议。隐藏菜单不取消服务端权限检查，新版工作流不会自动接管旧采集。
- 故障事件/平台诊断：查询事件后按需执行只读诊断，回查证据。
- AI数据留存：预览过期正文数量，再确认清理。诊断技能、AI执行记录的未接入占位页已删除；Fixture演示保留直接开发地址，不进入导航和搜索。

Go管理器启动的本地预览自动建立内存会话，无需输入Token；失效需显式重新连接。手动开发模式的Token仍仅在当前标签页内存。服务地址和凭据见原local-preview说明，不在公共文档记录秘密。

数据库由所有者应用V031；受限运行角色按db/security/runtime-grants.sql补SELECT。关系表初始为空，不自动采集或生成关系。实际关系写入/编辑、分支并行、模型辅助编排仍未启用。真实验收范围见VALIDATION-REPORT §74与ADR-058。
