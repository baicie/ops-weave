# 画布、关系图与页面入口

§89工作流增量：算子库支持拖入与按钮添加，端口可连线/删线，连接表单提供键盘替代入口；显式MERGE支持分支合流，环、孤立节点和普通节点多输入不能保存。发布版本只读；已发布ENTITY可展开运行管理显式写入与启停本地任务，不自动发起采集。步骤/图形和运行展示组件已抽离，详见[工作流说明](workflows.md)与[ADR-061](../adr/061-editable-transform-graphs-and-runtime.md)。下文§74单链限制是当时的历史范围。

从“工作台 → 运维工作台”进入。概览显式读取当前授权范围的第一页资产与故障；“接入指南”按“选择数据源 → 数据工作流 → 工作流运行记录”介绍配置和测试。布局与数据范围见[运维控制台](admin-console.md)。

- 数据源中心：选类型，在抽屉保存来源，直接准备未保存的本地工作流；输出类型由输出节点配置。
- 数据工作流：默认X6画布，点击节点在右侧配置参数，也可切换编号步骤。测试数据和工作流库按需展开。拖动只改变位置；上移/下移改变单链执行顺序。拖空白平移，普通滚轮滚动页面，Ctrl/⌘+滚轮缩放，适应按钮显示全部节点。保存、预览通过后发布固定版本，已发布版本只读。
- 工作流运行记录：查询转换成功/失败/过滤和节点错误；和Zabbix的采集运行记录不同。
- 实体模型/关系模型：定义结构和端点，不代表实体或关系实例已产生。关系模型内G6示意来自已发布目录。
- 资产关系图：读取资产，选择起点；G6展示受权且当前有效的直接关系。点击节点或下方列表查看详情，明细表展示方向、类型和来源。超过50条时提示截断，空图不补造关系。
- 关系实例：在已授权资产之间维护已发布关系类型的实例。当前关系/维护历史两个视图、状态列与详情抽屉；终止需填写理由并写入有效结束时间，历史保留原记录与终止理由。终止结果未知时保留原请求编号与内容，只能显式“查询原请求结果（原样重试）”。行内「更正关系」（详情抽屉也可进入）显式更正端点/关系类型：理由必填、带对象版本校验，原关系记录与历史不被改写（原记录只写有效结束时间并由更正记录关联到新记录），已终止的关系不接受更正；更正结果未知同样保留原请求编号，只能显式原样重试。详情抽屉的多来源确认视图逐条展示来源类别/来源标识/批次标识/数据模式/确认时间与撤回状态，并提供「登记来源确认」与「撤回来源确认」表单：每条来源确认独立记录，来源确认与人工断言互不改写，单一来源失效只撤回它自己的确认（其他来源仍确认时关系保持有效），全部确认撤回才按终止流程写有效结束时间并保留历史；冲突显式 409，不静默覆盖。「登记外部链接」抽屉把显式外部对象键（命名空间/对象类型/外部键/代次/目标实体）确定性绑定到已授权实体，使未登记即待处理的关系端点可解析；不按名字/IP 猜测、不改写既有实体归属。登记同请求编号内容变更 409，同键已绑其他实体显式 409 不静默改绑；登记结果未知保留原请求编号，只能显式原样重试；身份切换清理表单状态。
- 接入维护：该分组暂从导航和搜索隐藏；Host采集维护、CMDB快照导入、资产绑定纠错保留原直接地址及各自授权、预览确认协议。隐藏菜单不取消服务端权限检查，新版工作流不会自动接管旧采集。
- 故障事件/平台诊断：查询事件后按需执行只读诊断，回查证据。
- AI数据留存：预览过期正文数量，再确认清理。诊断技能、AI执行记录的未接入占位页已删除；Fixture演示保留直接开发地址，不进入导航和搜索。

Go管理器启动的本地预览自动建立内存会话，无需输入Token；失效需显式重新连接。手动开发模式的Token仍仅在当前标签页内存。服务地址和凭据见原local-preview说明，不在公共文档记录秘密。

数据库由所有者应用V031；受限运行角色按db/security/runtime-grants.sql补SELECT。关系表初始为空，不自动采集或生成关系。关系实例的人工创建/终止/历史、事务内基数与唯一性冲突策略已启用（ADR-100、ADR-101、第146/167/168节）；来源关系输出的配置/执行/回执展示已启用（端点须已登记外部链接，未登记进待处理，见[工作流说明](workflows.md)）；外部链接登记入口已启用（第173节，确定性登记解决待处理端点解析）；关系端点/类型更正与多来源确认合并已启用（第174节、[ADR-102](../adr/102-relation-correction-and-multi-source-confirmation.md)：V066 记录更正历史与确认条目，显式更正记录保留原历史，单条记录多来源确认、单一来源失效只撤回自身确认，冲突显式 409 不静默覆盖）。分支并行、模型辅助编排仍未启用；多实例联测与真实环境验收未做。真实验收范围见VALIDATION-REPORT §74、§167、§168、§172、§173、§174与ADR-058、ADR-100、ADR-101、ADR-102。
