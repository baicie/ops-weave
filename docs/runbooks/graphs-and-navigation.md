# 画布、关系图与页面入口

从“工作台 → 开始使用”进入，按“选择数据源 → 数据工作流 → 工作流运行记录”完成配置和测试。每页顶部“使用说明”解释用途、步骤与相关入口。

- 数据源中心：选类型、确认目标模型，在抽屉确认后打开草稿。
- 数据工作流：X6画布。点击节点配置参数，拖动只改变位置；上移/下移改变单链执行顺序。拖空白平移，普通滚轮滚动页面，Ctrl/⌘+滚轮缩放，适应按钮显示全部节点。保存、预览通过后发布固定版本，已发布版本只读。
- 工作流运行记录：查询转换成功/失败/过滤和节点错误；和Zabbix的采集运行记录不同。
- 实体模型/关系模型：定义结构和端点，不代表实体或关系实例已产生。关系模型内G6示意来自已发布目录。
- 资产关系图：读取资产，选择起点；G6展示受权且当前有效的直接关系。点击节点或下方列表查看详情，明细表展示方向、类型和来源。超过50条时提示截断，空图不补造关系。
- 接入维护：Host采集维护是旧v1入口；CMDB快照导入、资产绑定纠错保留各自协议与预览确认。新版工作流不会自动接管旧采集。
- 故障事件/平台诊断：查询事件后按需执行只读诊断，回查证据。
- 诊断技能/AI执行记录/AI数据留存：配置诊断能力、查看执行及费用、管理正文留存。Fixture演示放在开发演示分组。

本地开发Token只在当前标签页内存，刷新后重新填写；无Token时说明中给出入口，不绕过后端权限。服务地址和凭据见原local-preview说明，不在公共文档记录秘密。

数据库由所有者应用V031；受限运行角色按db/security/runtime-grants.sql补SELECT。关系表初始为空，不自动采集或生成关系。实际关系写入/编辑、分支并行、模型辅助编排仍未启用。真实验收范围见VALIDATION-REPORT §74与ADR-058。
