# 数据源中心

入口：Web侧栏「数据接入 → 数据源中心」，地址 http://127.0.0.1:5173/#/integrations/sources 。

1. 先建立平台会话。开发模式在顶部输入本机开发Token（本地忽略文件.tmp/local-preview/secrets.json中的devToken，不能使用模型API Key）；刷新或会话过期需要重新填写。未认证时页面会解释原因，点击类型不会发送API请求。
2. 选择Zabbix或JSON手工样本，页面按需读取授权目录并打开配置抽屉，不必先点「读取数据源」。顶部读取按钮用于显式刷新目录。输入名称、说明，选择内置或已发布自定义实体模型。
3. Zabbix显示平台当前配置的连接，可点击「测试连接」查看来源模式和报告版本。Fixture会明确显示为合成自检。连通性探测不是完整采集兼容验收。
4. 点击「确认并进入画布」，原子保存本人接入配置与第一版草稿。默认含映射、去除空白和模型校验，可继续调整清洗节点。
5. 手工样本在画布输入；Zabbix使用已存在Host批次UUID。手动保存/预览后才能发布，所有预览和版本测试仍只读。
6. 返回数据源中心读取「我的接入配置」，可查看创建时配置和继续编排。刷新浏览器后重新授权再读取；不能依赖浏览器持久保存Token。

保存异常时，抽屉保留原确认命令和UUID，使用「查询确认结果」或「按原配置重试」。关闭后也可重新读取列表核对。不会后台自动重试，也不会自动采集。列表最多20份、每主体容量200份、活动草稿上限50份。

当前只选择一条平台已配置的Zabbix连接；地址和凭据引用只读，不能在页面新增另一实例。多个接入方案不等于多个数据源连接。连接配置仍使用现有环境变量/密钥引用部署流程，密钥不得粘贴到接入说明或普通日志。创建时来源模式持久保留，当前配置改变不会将旧Fixture回执改称真实来源。

CMDB快照卡片前往已有导入页，画布配置尚未开放。接入回执是不可变创建快照；后续工作流编辑与新版本以画布为准，继续编排始终打开第一版。实体/关系实例输出、自动采集绑定和AI协助后续开发。

数据库由迁移所有者应用V030__source_setup.sql；受限运行角色补充integration.source_setup的SELECT/INSERT（db/security/runtime-grants.sql）。确认与工作流草稿共用事务，不增加数据库或服务。新表授权SQL已提供不等于运行角色脚本已复验，实际验证范围见VALIDATION-REPORT §71。
