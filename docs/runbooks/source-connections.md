# 创建与维护连接

先由部署配置提供[受控地址目录](source-endpoints.md)和[凭据存储](source-credentials.md)，由可信身份配置SOURCE_SYNC/SOURCE_CONFIGURE和对象范围。页面上的按钮不会扩大权限，未配置地址或凭据不可创建连接。

1. 数据源中心→实例管理→新增连接，填写名称/说明。
2. 选择登记地址、凭据和具体版本。被撤销的版本保留展示，不能提交；不自动选择“最新”版本。
3. 创建连接只保存配置。成功后可在列表中维护实例→连接与字段，明确发起测试或发现。
4. 维护实例→地址与凭据，查看已保存完整地址/秘密版本，修改后显式保存。名称说明变更保持配置版本；地址或秘密版本变化才生成新配置。
5. 连接历史按需读取，旧快照保留。保存结果未知时输入锁定，只查询原连接回执；不能拿当前配置冒充原请求结果。普通错误保留草稿，显式重新读取或放弃修改；关闭后可从继续配置连接恢复。

地址或秘密轮换不会自动更改已有实例、发布流程或任务。AVAILABLE表示目录pin和固定秘密/密钥元数据当前可用；连接是否可读以显式测试结果及时间为准。旧env来源尚未显式绑定固定版本时仍LEGACY，成功读取也不会显示可复用的CURRENT凭据语义。

发现仅报告首分页最多5条Host的5个原始字段类型/缺失，不存原始值；不表示完整指标/模型发现。新连接的工作流完整pin和实际运行尚未接入，因此新实例暂从实例管理操作，不能用旧部署来源的流程绕过固定配置绑定。已有流程按原版本继续执行。

生产TLS/IdP、密钥备份恢复、最小运行数据库角色、后台委托和多副本故障验收必须单独完成；本机dev配置及Fixture不能作为这些能力的证明。公共API和摘要详见[连接契约](../../contracts/source-connections.md)与ADR-066。
