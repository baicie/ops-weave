# 查看模型差异与引用

打开实体或关系模型目录。列表自动读取一次，可按名称或完整模型标识筛选；关系图按需展开。点击名称在右侧查看固定版本，字段显示完整 `模型标识.字段标识`。

打开“固定版本引用”查看当前可读取的关系类型、工作流版本和自己的任务摘要。点击工作流名称跳转到明确工作流版本；点击完整字段名跳转到明确模型版本的对应字段。只有当前授权范围内的结果，截断或未读取工作流时会明确显示。刷新按钮用于人工重读，不自动轮询。

创建或编辑私有草稿后先保存，系统自动检查该份草稿一次。检查列出原版本、候选版本和每项兼容性；存在不兼容修改或读取失败时，发布按钮保持禁用。编辑后须再次保存；错误后可“重新检查版本”。允许追加可选字段和调整显示名称/说明，既有字段含义、必填、长度、数值范围及枚举保持。关系端点和基数保持。

检查通过后仍须点击“发布模型版本”。服务器重新校验当前草稿和最新版本，冲突时重新读取并处理自己的草稿。发布不会转换历史资产、改变固定引用、重启任务或升级工作流；升级工作流需显式创建新版本、重新选择目标并验证发布。

模型链接使用 `#/modeling/entities?definition=custom.example&revision=2&field=name` 或关系目录的同类参数。自定义固定版本不在列表前50项时仍按明确版本读取；找不到或字段不存在时显示错误，不能替换为其他版本。

身份变化清除私有内容并取消迟到响应。列表、引用、差异只读展示不存入浏览器持久存储。具体协议和限制见[模型影响契约](../../contracts/model-impact.md)，实际验证见[验证报告](../VALIDATION-REPORT.md)第119节。
