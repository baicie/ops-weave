# 使用数据工作流

第114节任务控制补充：启动/停止需原请求UUID，响应丢失保留原输入并查询受理回执；确认后另读当前状态，不自动重发或采用旧任务快照。相同请求返回原结果，不重新签发授权；客户端与平台须成对升级。交互、容量及回退见[任务控制确认](workflow-runtime-control.md)。

第113节实体后台补充：OIDC与PostgreSQL环境可由操作员显式开放限时后台授权，用户启动原Host实体任务后查看期限、已用批次和撤权原因。最长15分钟/20批，关闭页面或注销后仍可在授权期内运行；停止任务可终止。默认无许可，固定接入配置和指标/日志后台尚未开放，失败不推进游标。配置与恢复边界见[后台任务授权](workflow-background-authority.md)。

第112节指标补充：指标输出可选择完整标准指标及固定映射，字段、转换、范围和维度进入实际预览计划，见[标准指标映射](workflow-standard-metrics.md)。支持[固定真实指标来源](workflow-metric-sources.md)最近10分钟最多5点的只读转换。手工来源更换定义会重建节点和连线，可撤销；固定来源不自动替换映射，发布不启动指标采集或写入。

第105节算子补充：新草稿已固定算子；旧草稿使用更多菜单中的固定版本入口，保存并重新预览后发布。完整步骤见[固定算子版本](workflow-operators.md)。

已保存连接版本可在来源节点明确选择，见[固定连接版本](workflow-source-bindings.md)。即时只读预览不填写旧采集批次ID，发布不启动持续采集。

入口：本地 http://127.0.0.1:5173/#/integrations/workflows ，左侧“数据接入 → 数据工作流”。Go管理器的本地预览自动建立短时会话，独立手动开发模式或OIDC仍保留；服务端继续逐请求授权。

1. 工作流入口先显示处理流程表，可按名称/来源搜索，按实体、指标或日志筛选。点击流程名称或“查看版本”进入独立版本表，再用“编辑流程”打开草稿、“查看流程”打开发布版本。本地预览自动读取目录；独立手动开发模式需先授权并点击“打开工作流库”。来源中心的“继续编排”直接恢复对应来源或初版工作流。
2. 已确认来源直接进入画布，准备一份未保存的本地流程；不再经过输出选择卡片。Zabbix主机使用实体/主机模型，手工样本在实体目录可用时默认实体，没有实体目录时以日志样本格式开始。在左侧节点库的“数据输出”中选择实体、指标或日志；点击输出节点打开对应抽屉，实体输出在此选择固定模型版本，日志/指标显示各自记录格式。也可直接新建对应模板。日志与指标不要求实体模型；Zabbix主机模板只消费已有Host批次元数据，不作为日志/指标输入。切换输出类型或实体模型会重建默认字段映射并清除旧预览。
3. 默认显示处理画布，桌面左侧节点库分为“清洗与转换”“流程控制”和“数据输出”，可以搜索中文名称、规则说明或算子标识，如`SCALE`。拖入画布创建待连接节点，点击插入选中步骤后；添加后打开配置。画布工具行的“节点库”按钮展开或收起左栏；≤1000px默认收起，进入窄屏断点自动收起，按需展开。输入、映射、校验、输出是固定节点，库中提供7个实际处理算子和3类输出入口；输出入口切换同一固定OUTPUT节点，不创建多个输出端点，当前选中类型再次点击打开配置。步骤视图共用节点库。
4. 左键点击节点打开贴右全高配置抽屉，或右键/Shift+F10后选择“编辑节点”；已发布版本只读。抽屉显示节点标识、算子版本及对应参数，实体映射显示`builtin.host.hostname`这类完整名称，实际字段ID不变。关闭或Esc返回节点，保留字段；先收起抽屉再保存/预览。TRIM处理全部文本字段，无额外参数；MERGE合并同一记录的分支，同名字段值冲突拒绝。连接仍可拖动底部输出端口到顶部输入端口，或用“连接与分支”表单建立/删除；孤立节点需连通后保存。上移/下移仅用于单链，拖动节点只改位置。
5. 点击“字段映射”，左列填写来源字段名，右列显示输出字段。展开“测试数据与结果”填写1到5条JSON记录；默认示例标记为Fixture。Zabbix填写已有Host采集批次ID，此操作不触发新采集。
6. 编辑工具栏保留“保存草稿 / 预览当前草稿 / 发布版本”。更多菜单提供返回版本列表、运行记录、读取列表、放弃本地修改、节点/输出配置、撤销/重做和排列；原禁用条件继续生效。保存后预览，选择节点查看输入、输出与中文错误；通过、拒绝、过滤分开计数，缺失Raw、截断、来源模式和失败状态保留。样本不随草稿持久化。
7. 至少1条通过且无拒绝，15分钟内可“发布版本”。修改规则或测试数据后重新预览；移动坐标不改变语义。发布不会启用采集或写入实体、时序库或日志存储。
8. 发布后定义只读，保留“测试运行已发布版本”和“创建下一版”，实体流程另有“执行与任务管理”，不显示保存、发布、添加步骤按钮。“返回版本列表”查看同一流程的最近版本，“全部处理流程”回到流程表。“新建工作流”打开模板选择对话框；无实体目录权限时实体模板不可用。刷新后从版本表继续打开；运行历史保留回执及新运行的逐条节点状态/错误原因；输入和输出正文不保存，逐步输出需再次显式测试运行。

画布下方仅保留按需展开的“测试数据与结果”，已发布实体的运行管理继续独立折叠。编辑区不再重复显示工作流库、目的地预览说明和执行说明；查找其他流程/版本使用顶部返回入口。多页签切离时关闭节点与连接浮层，返回后按需打开，未保存字段仍在原页面内存。

网络结果不明时先重新读取草稿/已发布列表核对。保存使用editVersion防止覆盖；原样发布重试会返回同一版本。测试运行没有隐藏重试，每次显式执行新增一份回执。放弃本地修改恢复最后保存版本，未保存的新模板会被关闭。

默认排列的节点间保留64px空隙，单链对齐端口并使用直线，分支绕过中间节点。已有草稿不会自动覆盖手动坐标；点击“排列”采用新间距，点击“适应”完整查看，排列可撤销。发布版本的布局仍只读。见VALIDATION-REPORT §90。

编辑区顶部工具栏集中名称、版本状态与保存/预览/发布操作；主要按钮随当前可用步骤强调，原禁用条件不变。下方画布和当前节点配置共用一个容器，点击节点显示蓝色选中标记，输出类型及目标模型在输出节点设置，手机布局为上下排列。测试数据、结果和工作流库仍按需展开。发布版本的字段保持禁用，只能显式测试或创建下一版；源码参考与三种宽度的检查见VALIDATION-REPORT §84。

当前上限：50个活动草稿/用户、200份运行回执/用户、200个发布版本/租户。满额明确报错；本段未实现回执保留清理、全部历史分页或运维删除入口。

流程表合并本次读取的最近20份草稿和20个发布版本，同一流程只列一行；筛选只作用于当前列表。版本表按修订号排列，列表截断时保留提示，较早版本仍可使用原有 `?id=…&revision=…&state=…` 链接读取。`?task=…` 只选择当前目录中的流程版本，不新增接口或假装完整分页。查看列表、切换版本和视图不触发保存或执行。

现有v1接入流水线与历史版本继续使用旧入口。v2保存/预览/发布只读；实体写入由已发布版本显式启用，见下文。关系、通用HTTP、脚本、模型节点或修复动作仍未接入。Zabbix版本差异继续由已有Java连接器和v1映射适配，画布不能绕过它；现有本地7.0.27批次不能证明其他厂商版本已验收。

数据库升级：由迁移所有者应用V029；受限平台运行角色使用db/security/runtime-grants.sql补齐workflow_draft的SELECT/INSERT/UPDATE以及workflow_version/workflow_run的SELECT/INSERT。已发布版本和回执不给UPDATE/DELETE。四个启动单元不变。工作流基础验证见VALIDATION-REPORT §70，运行记录增量见§73；设计见ADR-055与ADR-057。

新建推荐入口为[数据源中心](source-center.md)：选择类型→配置来源→确认保存→处理画布→配置输出节点→显式保存工作流。进入画布不发送工作流保存、预览或发布请求。工作流页仍可直接创建模板；旧v1 Host流水线继续保留。接入方案不是自动采集绑定。

## 查看成功、失败与过滤明细

进入“数据接入 → 工作流运行记录”，授权后读取最近20次预览/版本测试。按转换结果或工作流/运行ID筛选当前列表，点击“查看明细”查看计数、来源与输出类型（实体还显示模型版本）、执行耗时、节点统计和逐条结果；失败记录默认展开，提供字段、中文原因及稳定错误码。也可以输入完整运行UUID回查更早记录。“工作流库”内每条运行回执可直接跳转详情。

受阻的下游节点标记未执行；DAG的独立分支仍显示实际执行状态。过滤是按规则跳过，不计失败。转换全部通过仍不代表来源完整或实体写入；上游失败、缺失Raw和截断会另行提示。刷新后用原会话重新授权读取即可，读取不重新执行、不调用模型。旧回执仅有计数时页面明确提示没有逐条明细。

历史记录不保存样本/节点输出正文；当前画布节点输出仍仅本次响应可见。请求级错误（例如非法JSON、鉴权失败、来源读取失败）暂不形成持久运行详情；本入口是v2工作流测试运行历史。

“画布视图”由 AntV X6 渲染：拖动节点改位置，拖空白平移，普通滚轮滚动页面，Ctrl/⌘+滚轮缩放；“适应”显示全部节点。端口连线与连接表单共用校验；SOURCE→MAP和VALIDATE→OUTPUT固定，其他可编辑。普通节点可分流但只有一个输入，多输入要用“合流”节点，同字段不同值拒绝。未连通节点、环和超限图不能保存。菜单旧v1入口为“接入维护 → Host 采集维护”；详见[图形与导航说明](graphs-and-navigation.md)。

## 日志与指标输出

日志格式1.0要求eventTime（带时区）和body（非空白正文），可选severityText、serviceName、traceId和spanId。预览将时间规范化UTC，默认保留正文首尾空白；日志模板不添加TRIM。如果明确添加「去除空白」，它会处理所有文本，包括正文。当前输入是已拆字段的平面JSON，尚未提供Grok或多行原始日志解析。

指标格式1.0要求timestamp、metricKey、value和metricType，可选unit；首版metricType仅GAUGE。value允许有限数字或可转十进制的文本，最多12位小数、绝对值不超过9007199254740991。单位换算需显式SCALE系数，不能把GAUGE、SUM、累计量和速率混为同义。

这5个字段是单条指标记录格式，不是指标种类数。指标映射/校验/输出抽屉可以展开“指标标识与定义参考”，显式读取已授权目录，完整展示`host.cpu.usage.user`等指标标识和来源键。点击完整标识进入“模型中心 → 指标定义”，查看名称、实体类型、单位、类型、来源键、转换和固定映射版本；返回目录与浏览器返回支持标准/多页签布局，失败需显式重试。现有内置目录实际3项，其他定义或实时采样不因界面改版自动增加。

两类输出均不绑定实体目录、不会创建占位实体。节点输入输出只在本次响应中展示，历史详情保留输出格式、状态及闭集错误码，不保存正文。保存草稿、有效预览、不可变发布、版本测试各有独立状态。真实指标写入、日志索引、后台持续接入、实体关联与自动启用尚未接通。见[ADR-060](../adr/060-source-first-typed-workflow-output.md)。

## 执行实体流程与任务启停

当前运行仅支持本地loopback开发认证与PostgreSQL，Java平台负责确定性执行，不另起工作流服务。OIDC生产后台委托、日志/指标持续输出尚未实现。

1. 打开已发布实体流程，展开“执行与任务管理”。填写输入中稳定唯一的来源标识字段（Zabbix为`entity_id`），选择最终输出中的文本名称字段。不要用易变的名称/IP代替业务ID。
2. 手工来源在测试区填写自己的平面JSON样本并明确标记数据来源，点击“执行并写入资产”。页面先运行只读测试，服务端校验同版本/同输入回执后才写入，面板显示已确认数量和执行标识。到“资源观测 → 资产”搜索该名称查看。
3. Zabbix来源可执行现有完整Host批次，也可点击“启动持续处理”。每5秒消费启动后新完成的已有批次；这不会发起采集。来源采集由既有维护接口/Worker配置单独管理。
4. 运行版本固定；修改流程需创建下一版，先停止旧版任务，再打开新发布版重新启动。任务控制有代次校验，冲突时刷新状态。重启platform会恢复RUNNING任务；失败不会自动恢复，修正原因后显式重新启动，启动从当前时刻开始，不补跑旧批次。
5. 点击“停止任务”，返回前等待已开始的写入批次结束；停止确认后不会开始下一批。即使实体写权限撤销，本人仍可停止已有任务。

同一稳定标识更新workflow独立来源实体，不自动合并到原Zabbix资产，不执行缺失退役。每批最多5条，缺失Raw、截断、不完整、批次失败、权限撤销、超过50条待处理批次会停止。最多20任务/200执行回执，每主体原有200只读测试回执限制仍保留，满额报错，未提供自动清理。

网络结果不明时显示“按原标识确认执行”，输入锁定，不能关闭待确认页；先刷新回执或原样确认。已确认FAILED可能有部分写入，修正原因后新测试/新执行，不自动重试剩余行。资产与回执分属事务，回执提交失败不证明资产未写入；保留原键确认。运行列表只有元数据，样本正文不落运行历史或本地存储。

迁移所有者顺序应用V032–V034；受限角色按runtime-grants.sql补齐task的SELECT/INSERT/UPDATE与execution的SELECT/INSERT。人工回滚脚本在db/rollback/platform，逆序执行，先停任务/导出所需元数据，超旧预算trace回滚会拒绝。详见[ADR-061](../adr/061-editable-transform-graphs-and-runtime.md)和VALIDATION-REPORT §89。


## 比较已保存版本

在工作流库选择流程，再点版本行“比较版本”；编辑器也可从更多菜单进入，需先保存本地修改。抽屉选择基准与对比版本后，点击“比较所选版本”；选项来自最近列表，单版本可比较自身。打开/切换选项不自动请求，也不保存、预览或发布。

差异按名称、来源配置、输出模型、算子、字段映射、节点参数、节点/连线和执行顺序分组；显示完整键和摘要，未设置与空字符串区分。不同revision本身、布局与预览回执不列为处理变化。比较不是兼容性或执行资格确认；固定依赖仍需经过原保存/预览/发布门禁。

编辑号或摘要过期时显示冲突，点击“刷新版本选项”，重新选择并明确比较。仅改画布位置也可能使旧编辑号过期；不自动覆盖草稿或换新版本。选项消失置空，刷新失败保持错误；关闭/切页取消，权限失效清空私有结果。Esc/关闭返回入口，手机表格与完整文本局部滚动/换行。契约见[工作流比较](../contracts/workflow-comparisons.md)。

第115节：已发布固定指标的实际样本写入、UNKNOWN原结果验证与当前点查询见[指标输出手册](workflow-metric-output.md)。发布和只读测试本身仍不写指标点；样本入口显式写入且最多5点，不推进持续采集checkpoint，也不创建资产绑定。

固定接入Host资产的有限后台批次、确认后checkpoint与显式停止/恢复见[资产扫描](workflow-host-scans.md)。旧完整采集批次和手工单次执行保留，连续指标/日志窗口仍单独验收。
