# 模型中心本地操作

打开 [实体模型](http://127.0.0.1:5173/#/modeling/entities)、[指标定义](http://127.0.0.1:5173/#/modeling/metrics) 或 [关系模型](http://127.0.0.1:5173/#/modeling/relations)。当前页面在平台会话就绪后自动读取一次授权目录，后续可点击“刷新目录”或“刷新”。未授权或后台页不读取；读取失败保留错误，点击“重试”后再请求，不随主题、尺寸或筛选变化重试。开发凭据仍只保存在当前标签页内存，不在文档或 URL 中传递。

内置指标使用列表，显示名称与完整指标标识、实体类型、单位、指标类型和完整来源键。名称或完整标识都可打开定义，再返回目录；搜索在当前授权目录内完成，不重复请求。窄屏在表格自身容器横向滚动。多页签返回已加载目录不重复读取；身份变化清除旧结果，新的有效会话可读取新目录。当前目录只有已有映射，不补造指标或实际采样。

1. 查看内置主机/应用/服务/数据库/网络接口，或“新建实体类型”。类型标识使用 custom. 前缀，例如 custom.web_service。
2. 添加标量字段，设置必填、文本长度、数值范围或枚举。模型定义只表示数据规则，并不创建资产。
3. 输入一条手工 JSON 样本，点击“预览清洗结果”。样本只在内存处理；缺失、null、类型错误与未知字段有独立说明。
4. 保存私有草稿，刷新后重新授权并读取目录可找回。编辑后的内容必须重新保存，再查看绑定这份草稿的兼容性差异；通过后才允许明确发布。
5. “发布模型版本”固定该版本与指纹；之后用“创建下一版本”追加可选字段或调整名称/说明。破坏性变更暂不支持，服务端会拒绝。
6. 关系模型选择起点/终点的已发布实体类型版本和基数，再保存/发布。这一步只定义关系类型，不添加实体间的关系实例。

内置类型可以复制为新的 custom.* 类型；当前还没有保留 builtin.* 类型标识的租户扩展层。已有 Host 资产没有自动套用新模型。指标目录只显示已有映射定义，实际采样到“指标”页读取。

Zabbix 当前已实测记录为本地 7.0.27，其他版本未验证。版本探测和认证/字段适配由连接器负责；默认清洗规则 safe-scalars-v1 面向平台字段，不随厂商版本任意改变。

权限与 API 细节见 [模型契约](../../contracts/model-catalog.md)。真实 PG 失败不能回退 memory；目录会显示明确的持久化或临时存储模式。保存结果不确定时先重新读取草稿，发生409时核对编辑版本，不自动覆盖。刷新、清除会话和身份变化都会清空页面中的模型及样本。


实体与关系目录已使用列表，关系图按需展开。固定版本抽屉显示字段全称，展开引用可查看当前授权工作流、映射字段及自己的扫描/周期任务；列表截断与工作流未读取均保留。操作和升级边界见[模型影响](model-impact.md)。
