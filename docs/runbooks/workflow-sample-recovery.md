# 终止单次样本确认

已发布接入流程的指标或日志样本结果 UNKNOWN 时，选中原记录会读取一次终止状态。原输出可能已经存在。勾选确认后点击“终止确认”，保留原证明及数据，不再核验这个原批次。成功后显示终止回执，原结果仍未知，可明确发起另一份样本请求；不能据此判断没有重叠或重复。

响应丢失或不符合契约时，不创建替代 UUID。点击“查询原终止回执”；只有查询404后才提供原内容重发或放弃本次本地确认。放弃不取消服务器命令，也不关闭原输出确认。命令待确认期间不能折叠、关闭页签或切换版本。元数据读取失败后明确重试，无自动重发或输出核验。

终止要求本人原证明、工作流与固定来源同步权限，以及对应指标读取权限，或对应日志读取/写入权限。原状态 PENDING、CONFIRMED、FAILED 均不能终止。PENDING须通过已有明确核验获得可信状态。元数据或输出端口失败不回退模拟能力。

平台和 Web 同步部署，先在既有 PG 应用 [V053](../../db/migrations/platform/V053__workflow_sample_recovery.sql)。回滚前停止兼容应用、导出并保护终止事件和原证明，确认旧应用可能重新提供原核验后再执行 [回滚脚本](../../db/rollback/platform/V053__workflow_sample_recovery.sql)。脚本只删除决策表，不删除或改变原输出；不能用回滚恢复已终止确认。

样本终止不改变持续任务代数、检查点或已终止版本；任务恢复使用[独立入口](workflow-recovery.md)。协议见[样本终止契约](../../contracts/workflow-sample-recovery.md)，实际检查见验证报告第131节。
