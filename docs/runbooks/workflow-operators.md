# 固定工作流算子版本

打开工作流库后，节点库使用该次授权响应中的算子目录；分类、搜索、点击与拖入沿用现有画布。新模板和新添加的节点已固定版本。选中节点，在右侧配置抽屉查看类型、版本和完整固定摘要。

旧草稿仍可编辑与预览。准备发布时，在“更多工作流操作”选择“固定算子版本”，检查修改，保存并重新预览；至少一条通过、没有拒绝且预览未到期后发布。该操作只修改当前页的内存草稿，可撤销/重做；关闭或切换仍受未保存门禁。已发布版本只读，修改应先创建下一版。

目录缺失时允许查看历史，暂不能新建或发布；目录不兼容时保留错误，核对前后端构建版本后显式刷新。不要通过重复点击发布、替换摘要或重新填入旧预览ID规避门禁。固定摘要不替代来源、模型或输出授权。

旧pinless已发布版本保持原版本1兼容执行，升级不回写历史。固定来源目前仍只支持即时只读预览和发布；后台采集与真实输出范围见[固定来源](workflow-source-bindings.md)。完整检查及未验收范围见验证报告§105。
