# 固定接入的资产扫描

在工作流中明确选择接入配置、实体模型及算子版本，保存、预览并发布。已发布固定ZABBIX_HOST来源的实体流程打开“执行与任务管理”，标识使用entity_id，选择输出中的实体名称字段，再“启动扫描”。开发身份必须是已有回环服务的可信开发身份；OIDC后台处理需操作员许可及当前有效授权，浏览器不能提交权限。

扫描每批最多5条，全部输出确认后继续下一批。状态区分别显示当前扫描的确认批数/来源记录数、最近批次的确认写入数和末批标记；过滤后的记录不等于写入资产数。规范资产保存在工作流独立来源命名空间，不覆盖原接入资产身份。当前是有限扫描，完成后自动停止，不宣称周期采集已经启用。

“停止任务”保留原游标和待处理批次。失败或停止后可“恢复原扫描”：核对同一固定版本和原设置，取得新的短时授权后沿原游标继续。原批次已受理时使用保存的数据和读取时间，不重新读取变化的上游内容。结果待确认时保留已有确认数，不能把UNKNOWN当成失败且零写入。新启动不能跳过未完成扫描；已完成后可显式开始新扫描或启动已发布的新版本。

控制请求响应丢失时查询原控制回执。404后可以显式重发相同UUID和内容；原回执表示受理时状态，当前任务和扫描另行读取。不要换UUID猜测重试。切换身份会清空页面的原命令及私有缓存，页面隐藏会取消读取；未确认控制结果阻止切换版本或关闭。

IN_FLIGHT中断后不会自动重发输出，60秒后成为UNKNOWN并停止，显式恢复才重新受理。资产输出用稳定Observation键拒绝不同内容重放；部分写入不推进checkpoint。当前依赖租户事务锁串行资产写入与停止，有界单执行器恢复已验收；跨系统事务、生产HA租约/fencing与多副本共享预算尚未验收。

固定连接不可用、凭据撤销、算子或模型摘要变化时保留checkpoint并拒绝恢复，不静默换最新版本。自动放弃旧扫描、周期调度、跨依赖迁移、保留期清理和连续指标/日志窗口继续开发。每位所有者最多200批，目录最多1000主机；授权最长15分钟/20批，到期或额度耗尽需要显式恢复。上游清单变化与失败不会触发资产删除。

实现与实际检查见[ADR-078](../adr/078-durable-fixed-host-workflow-batches.md)、[契约](../../contracts/workflow-host-scans.md)及验证报告§116。仓库外实际证据不作为Fixture输出能力的证明。
