# 查看实测排队时间

在固定发布版本的“检查统计”中选择一条观察。实测记录的详情显示排队毫秒、入队时间与开始执行时间。页面首次打开读取一次元数据，关闭再打开沿用已读结果；刷新和 UUID 查询由用户明确触发。查看详情不读取来源、不核验输出、不执行工作流。

“—”表示没有实测证据，“0 ms”表示已测区间不足 1 ms。当前值只表示同一本人、同次本地轮询的 FIFO 等待；不包含轮询之前或取得并发预算之前的时间。它不是来源耗时、窗口迟到、接入延迟或生产 SLA。一个出队任务检查两个窗口时可能有两条观察，但共享一个 dispatch；不能相加为两次等待。

较长等待可由前面的任务执行产生。先分别查看来源读取、转换及输出证明；来源成功或转换通过不能代替写入确认。STOP 或授权过期发生在等待期间时，执行器继续以当前状态拒绝来源 IO，不沿用队列快照授权。

旧观察保持原输出、游标和质量，未测量排队值留空。超出本地队列容量或非法时间明确失败，不截断、补零或自动重试。最近 20 条展示与每本人 200 条观察容量仍为现有边界；没有自动清理、完整历史、跨本人公平性或多副本租约保证。
