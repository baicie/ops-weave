## 标识与恢复关系

| 标识 | 来源和用途 | 恢复约束 |
|---|---|---|
| 同步 `DiagnosisRequest.runId` | 客户端生成、同步诊断幂等键；结果的 `record.id` | 超时仅以原 ID 查保存结果，不自动重新调用模型 |
| 持久提交 `requestId` | 客户端生成的受理幂等键；`ai-run-command` 不接受身份 | 未知受理先在本人运行页查原请求；显式重发须复用原内容与 ID，不以新 ID 补偿 |
| 持久 `runId` | 平台签发的稳定运行 ID | 查询、取消、恢复、事件均固定此 ID；同 run 恢复只增加 attempt；终态新调查另行提交 |
| AIInsight `record.id` | 当前执行器按该 AIRun runId 保存结果 | 运行成功与结果可读分别检查；读取仍受 Incident/当前身份/证据过期边界保护 |
| HTTP 关联 UUID | 通用 transport 每请求生成 | 只用于追踪，不能代替命令 requestId 或权限 |
